# 15. バランス調整 v1.5.0

- **ステータス**: 確定（2026-07-04 プランナーレビュー承認済み）
- **リリース**: v1.5.0 で一括リリース
- **対象**: パッチ全 10 種の再設計 / Tier ボスのソフトエンレイジ / 凍結耐性 / Wave クォータ制（早回し）/ ドキュメント整合

---

## 0. v1.5.0 の設計原則

1. **パッチは全て「上限（MAX）のない成長軸」を最低 1 本持つ**。
   漸近式（`T1 + (max - T1) × T / (T + 20)`）は**全廃**する。理由: 後半の Tier 上げ（合成）の意味がほぼ失われるため。マシン永続強化で漸近を全廃したのと同じ方針。
   固定値スケール（`+n × T` の絶対値付与）も全廃する。理由: HP・収入が指数で伸びる世界では即座に埋没するため。スケール基準は必ず「リジェネ / maxHp / 与ダメ / 獲得倍率」など、プレイヤーの成長に乗算で追従する量に置く。
2. **「耐久さえできればいつか勝てる」構造を排除する**。
   Tier クリアの関門である W30 ボスに DPS チェック（ソフトエンレイジ）を入れる。これにより耐久特化（Thunder の HP 吸収など）は「生存の手段」に留まり、火力不足はボスで必ず精算される。武器個別のナーフは行わない。
3. 確率軸は 100% で物理的に飽和するため、次の 3 パターンで無限成長を担保する:
   - **オーバーフロー型**: 100% 超過分を次の段階に繰り越す（doubleShot / instantKill / bonusDrop）
   - **別軸型**: 確率は飽和を許容し、別の無限軸を持たせる（freezeHit / burnHit）
   - **確定型**: 確率自体を廃止する（damageImmune）

## 1. パッチ再設計（全 10 種）

### 1.1 スケール式の新旧対応

| パッチ | 現行 (v1.4.x) | v1.5.0 | 無限軸 |
|---|---|---|---|
| killHeal | 撃破時 HP `+ceil(0.5×T)`（固定値） | 撃破時 **リジェネ 0.2 秒分 × T** を回復 | 回復量（リジェネ投資と乗算） |
| shieldRegen | Wave クリア時 HP `+5×T`（固定値） | **常時: リジェネ +5% × T**（パッシブ乗算） | リジェネ倍率 |
| boltCast | Wave クリア時 ボルト `+5×T`（固定値） | **常時: ボルト獲得量 +2% × T**（パッシブ乗算） | 獲得倍率 |
| bossKiller | 上位敵への与ダメ `+5%×T` | **変更なし**（既に線形・上限なし） | 与ダメ倍率 |
| doubleShot | 発動率 漸近 5%→50% | 発動率 **`5% + 1.5%×(T-1)`** 線形・上限なし、**超過繰り越し** | 発射数 |
| instantKill | 発動率 漸近 2%→20% | 発動率 **`2% + 0.6%×(T-1)`** 線形・上限なし、**超過繰り越し** | 即死数 |
| bonusDrop | 発動率 漸近 5%→50%、ネジ ×2 | 発動率 **`5% + 1.5%×(T-1)`** 線形・上限なし、**超過繰り越し**（×3, ×4…） | ドロップ倍率 |
| freezeHit | 発動率 漸近 5%→50% | 発動率 **`5% + 1.5%×(T-1)`**（100% で飽和・繰り越しなし）+ **新規: 凍結中の敵への与ダメ +2% × T** | 凍結中与ダメ |
| burnHit | 発動率 漸近 5%→50%、DoT 30% 固定 | 発動率 **`5% + 1.5%×(T-1)`**（100% で飽和）+ DoT **`与ダメの (30 + 3×T)% /秒`** | DoT 係数 |
| damageImmune | 被弾時 漸近 3%→30% で無効 | 確率廃止。**Wave 開始時にバリア T 枚**展開、1 枚 = 被弾 1 回完全無効、**Wave クリアで全充填** | バリア枚数 |

### 1.2 各パッチ詳細

#### killHeal（キル時回復）
- 効果: 敵撃破時、`現在のリジェネ/秒 × 0.2 × T` を回復。
- T5 で 1 kill = リジェネ 1 秒分。Wave 約 20 kill で自然リジェネの約 +77% 相当。
- リジェネ永続強化（×1.02/Lv）と乗算で伸びるため、恒久投資と噛み合う。殲滅が速いほど回復が伸びるキルヒール。

#### shieldRegen（シールド再生）
- 効果: 装着中、リジェネを `× (1 + 0.05 × T)` に乗算（常時パッシブ）。
- トリガー `onWaveClear` を廃止し **passive** に変更（実装注意: パッチ基盤に passive 型トリガーの追加が必要。boltCast も同様）。
- T20 でリジェネ 2 倍。killHeal（キル反応）との差別化は「無条件・常時」。

#### boltCast（ボルト鋳造）
- 効果: 装着中、ボルト獲得量 `+2% × T`（常時パッシブ。マシン「ボルト獲得倍率」と乗算で重ねがけ）。
- T5 = +10%、T25 = +50%。収入スケール（tierScale）に自動追従する。
- **役割分離**: ネジ系経済パッチ = bonusDrop / ボルト系経済パッチ = boltCast。

#### bossKiller（ボスキラー）
- 変更なし。`上位敵への与ダメ +5% × T`（線形・上限なし）で v1.5.0 原則を既に満たす。

#### doubleShot（ダブルショット）— オーバーフロー型
- 発動率 `p = 5% + 1.5% × (T-1)`、上限なし。
- `p > 100%` の超過分は次段に繰り越す: 追加発射数 = `floor(p) + (rng < frac(p) ? 1 : 0)`。
- 例: T64 で p=100%（確定 2 発）、p=150% なら確定 2 発 + 50% で 3 発目（期待ダメ ×2.5）。期待倍率は常に `1 + p` で連続。

#### instantKill（インスタントキル）— オーバーフロー型
- 発動率 `p = 2% + 0.6% × (T-1)`、上限なし。対象は雑魚（normal）のみ（現行どおり）。
- 超過分は「**フィールド上のランダムな雑魚 1 体を追加即死**」に繰り越し（p=200% なら攻撃対象 + 1 体確定、以降同様）。

#### bonusDrop（ボーナスドロップ）— オーバーフロー型
- 発動率 `p = 5% + 1.5% × (T-1)`、上限なし。対象は**ネジのみ**（現行どおり）。
- 超過分は倍率段階に繰り越し: 倍率 = `2 + floor(p超過)`、端数は確率で +1（p=150% → 確定 ×2 + 50% で ×3、期待 ×2.5）。

#### freezeHit（凍結ヒット）— 別軸型
- 発動率 `5% + 1.5% × (T-1)`。100% で自然飽和（繰り越しなし）。
- 凍結時間 `1 + 0.2 × T` 秒: 現行維持。
- **新規無限軸**: 凍結中の敵への与ダメ `+2% × T`（上限なし、「凍らせて砕く」）。
  §2.2 の凍結免疫でアップタイムが最大 33% に構造固定されるため、高 T の成長はこの軸が担う。

#### burnHit（燃焼ヒット）— 別軸型
- 発動率 `5% + 1.5% × (T-1)`。100% で自然飽和。
- 燃焼時間 `1 + 0.2 × T` 秒: 現行維持。
- DoT: `与ダメの (30 + 3×T)% /秒`（線形・上限なし）。T24 で毎秒 100%（通常攻撃 1 発分/秒）。時間 × 係数で総 DoT は T に対して二次成長。

#### damageImmune（ダメージ無効 → ダメージバリア）— 確定型
- 確率判定を廃止。**Wave 開始時にバリア `1 × T` 枚を展開**。**Wave クリア（進行）で全充填**。
- **消費単位（実装確定）**: 被ダメは「接触中の敵の DPS × 経過時間」の連続方式で離散的な「被弾 1 回」が存在しないため、**1 枚 = 敵 1 体の新規接触 1 回を無効化**と定義する。新規接触の瞬間に 1 枚消費し、その敵の接触が途切れるまでの被弾を完全無効。ノックバックは通常どおり適用する（敵は接触後にノックバックされるため接触は離散的に発生する）。
- T1 = 1 枚/Wave。被弾頻度は敵数に比例するため相対価値は Tier に依らず安定し、確率型と違い **100% = 完全無敵に到達しない**。
- UI: 残枚数を HP バー付近に表示（装着中のみ）。

## 2. 敵・ボス

### 2.1 W30 Tier ボスのソフトエンレイジ（新規）

「耐久していればいつか勝てる」構造の排除。**Tier ボスのみ**が対象（elite / miniboss は対象外）。

- ボス出現から **60 秒間は等倍**（猶予）。
- 以降 **30 秒ごとに ATK を ×1.4 累積乗算**（上限なし）。凍結・ノックバック中もタイマーは進行する。

| ボス出現からの経過 | ATK 倍率 |
|---:|---:|
| 0〜60 秒 | ×1.0 |
| 90 秒 | ×1.4 |
| 120 秒 | ×1.96 |
| 180 秒 | ×3.8 |
| 300 秒 | ×14.8 |
| 420 秒 | ×57.6 |

- 適正 DPS（数分以内に撃破）なら実質無縁。耐久一点張りは 5 分で ATK 15 倍に達し必ず押し切られる。
- **ボス戦中の雑魚湧き頻度の緩和**: DPS チェック導入に伴い、ボス HP 60% 未満で再開する雑魚スポーンの間隔を**現行の 2 倍（頻度半分）**にする。ボス出現前（0〜25 秒）の湧きは現行どおり。
- UI: エンレイジ発動中はボス HP バーに警告表示（色変化 or アイコン）。
- 副次効果: Thunder（HP 吸収による耐久型）の強すぎ問題は、武器を触らずこの構造側の修正で均衡させる。**Thunder 本体・他武器の数値は v1.5.0 では無調整**。

### 2.2 凍結耐性（新規・全敵）

CC ハメ（高攻撃速度 × 凍結パッチによる永久凍結）の構造的排除。

- **全敵**: 凍結終了後、`凍結時間 × 2` のあいだ凍結免疫（アップタイム上限 33%）。
- **上位敵（elite / miniboss / boss）**: 加えて凍結時間そのものを `× 0.5`。凍結:免疫 = 1:2 の比率は変わらないためアップタイム上限は同じく 33% だが、1 回あたりの絶対凍結時間が半分になる（ボスが長時間止まらない）。
- 免疫中は freezeHit の発動判定自体をスキップ（発動演出も出さない）。
- **実装確定**: 免疫期限は凍結付与時に `凍結終了時刻 + 凍結時間 × 2` として即セットする。凍結中の再付与（従来の「長い方に延長」）は廃止 = **凍結は重ねがけ不可**。
- エンレイジ（§2.1）と併せ、「ボスを凍らせ続けて時間を稼ぐ」戦法は成立しない。

## 3. Wave クォータ制（早回し）

### 3.1 背景

W1〜W29 は 26 秒固定進行のため、火力がどれだけあっても 1 ラン最短 13 分固定だった。これにより Tier 差分攻撃力バフ（v1.3.4、`1.2^diff`）の意図「低 Tier 周回 = 差分攻撃力で速攻」が成立していなかった。

### 3.2 仕様

- **クォータ数**: `N(W) = floor(26 / スポーン間隔(W))`。スポーン間隔は現行の `2 / spawnFactor(W)` をそのまま使用（= 湧き総量は現行と同一）。例: W1 = 13 体、W30 相当 = 26 体。
- **湧きペース（撃破連鎖の前倒し湧き）**: 次の湧きタイミングは「**通常間隔の経過**」または「**場のクォータ敵が全滅した瞬間**」の早い方。火力が高いほど湧きが連鎖加速する。弱いうちは現行と完全に同じ体験。
- **v1.5.1 バースト拡張** *(v1.5.2 で見直し・下記参照)*: 場が空になった瞬間の前倒し湧きを 1 → 最大 5 体にバースト化した。ただし wave 開始直後にも 5 体同時湧きが発火し、通常プレイヤーの体感難易度を上げる副作用があった。
- **v1.5.2 湧きウィンドウ圧縮**: 上記の副作用を解消するため、**非 boss wave の湧きを前半 `SPAWN_WINDOW_SEC = 13` 秒に集約**する形に変更。`NON_BOSS_SPAWN_COMPRESSION = 2` で time-based の実効 interval を半減（W1 で 2s → 1s）し、全 quota を wave 前半で湧かせる。後半 13 秒は追加スポーンなしの kill バッファ。バーストは `EARLY_SPAWN_BURST_MAX = 1`（v1.5.0 相当）に戻す。
  - 強プレイヤー: 湧き終了とほぼ同時に殲滅 → 最短 15 秒前後で wave 完了
  - 通常プレイヤー: 同時接触数は v1.5.0 相当（バースト無し）に戻り、体感難易度は元に戻る
  - 総湧き数 (quota) は `floor(13 / 1) = 13`（W1）で v1.5.1 と同じ。報酬総量・難易度スケールは不変
  - boss wave (W30) はこの圧縮の対象外（ボス湧き規則は現行維持）
- **Wave 進行条件**: 「クォータ N 体を湧き切り済み **かつ** 場の敵が 0」で即座に次 Wave へ進行。26 秒経過時の強制進行（未殲滅の残敵持ち越し）は現行どおり。持ち越し敵は「場の敵 0」判定に含める。
- **上位敵 Wave（W5/W10/W15/W20/W25）**: 上位敵はクォータ外として追加スポーン。**湧き時刻は「通常の 25 秒（`durationSec - 1`）」または「クォータ全滅時」の早い方**（前倒し湧き。早回しで上位敵がスキップされ報酬・パッチ源を失うことを防ぐ）。上位敵も「場の敵 0」判定に含めるため、Wave 進行には上位敵の撃破が必要。
- **W30**: **現行維持**（クォータ制の適用外。25 秒でボススポーン、ボス HP 60% ルール、撃破で advanceTier）。
- Wave クリア時トリガー（バリア再充填等）は早回し進行時にも発火する。

### 3.3 意図

- 格下 Tier は数分で周回可能になり、Tier 差分バフと火力投資が**周回時間**に還元される。
- 湧き総量が現行と同一のため、報酬総量・難易度バランスへの影響は中立。

## 4. 据え置き（検討のうえ変更しない項目）

v1.5.0 レビューで検討し、意図をもって**変更しない**と確定した項目。

| 項目 | 判断 | 理由 |
|---|---|---|
| 敵成長率（HP ×1.8/T、ATK ×1.4/T）・報酬 ×2.25/T・強化コスト曲線 | 据え置き | 何度も周回する前提の設計。長期の周回数増加は仕様として許容 |
| パッチドロップ（Tier ボス限定 20%・1 ラン最大 1 個） | 据え置き | エンドコンテンツとして渋くてよい。patchDropRate MAX（Lv50 = ×5.0）で 100% に到達可能 |
| Thunder の HP 吸収（与ダメ × 0.1% × Lv・上限なし） | 据え置き | ナーフによる調整は萎える。エンレイジ（§2.1）で構造側から均衡 |
| 武器へのマイルストーン強化・防御特性の追加 | 見送り | 同時ヒット数等を動かすと武器間バランスの調整が不可能になる |
| 経済系マシン強化（+3%/Lv 線形） | 据え置き | 収入自体が Tier で指数成長するため、序盤〜中盤の味付けとして機能すれば足りる |

## 6. 実装時の検証項目

CLAUDE.md の検証ゲート（vitest / eslint / tsc）に加え、以下をシミュレーションテスト（vitest）で確認する:

1. **エンレイジ**: Tier 帯ごとの適正 DPS ライン（撃破所要時間 60〜180 秒想定）とエンレイジ発動タイミングの整合。
2. **凍結**: 発動率飽和時のアップタイムが雑魚 ≤33% / 上位敵 ≤20% に収まること。
3. **バリア**: Tier 帯ごとの Wave あたり被弾回数を計測し、`1×T` 枚の無効化率が過剰（実質無敵）にならないこと。
4. **オーバーフロー**: doubleShot / instantKill / bonusDrop の期待値が p に対して連続（100% 跨ぎで段差なし）であること。
5. **burn / freeze**: 新 DoT 係数・凍結中与ダメ増を含めた武器別 DPS 比較（v1.1 の DPS 表の再計算）。
6. **クォータ制**: 高 DPS 時の 1 ラン所要時間の短縮率、および低 DPS 時に現行と同一挙動であること。
7. **T1 初見バランス（TODO・実測）**: T1W30 ボス ATK 14,400（200 × 24 × W30 係数 3）に対し初期 maxHp 10,000 で接触 = 即死となる点が、初見プレイヤーの離脱ポイントになっていないか実機確認する。
