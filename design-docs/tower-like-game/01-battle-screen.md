# 01 — バトル画面 (Battle Screen)

ラン中、プレイヤーが実際に戦う画面。本作の体験の中心。片手スマホ操作で完結することを最優先とする。

**具体的なレイアウト・配色・余白・アニメーション秒数は claude design に委譲し、本章では情報設計（情報の種類・操作の種類・状態遷移）に専念する。**

---

## 1. 画面構成の概要

```
┌──────────────────────────────────────┐
│ [上 HUD: HP / Tier / Wave]              │  ← 上端固定
│                                      │
│              ▲ 敵                      │
│           ◇ 敵    ◇ 敵                   │
│                                      │
│        ◇          ★          ◇         │  ← ★ = マシン（中央固定）
│            (索敵円が常時表示)              │
│                                      │
│           ◇ 敵    ◇ 敵                   │
│              ▼ 敵                      │
│                                      │
│ [下 HUD: ネジ / アクティブ / 速度 / 一時停止 │  ← 下端固定（親指帯）
│         / メニュー / スクリーンセーバー]   │
└──────────────────────────────────────┘
```

- マシンは常に **画面中央固定**
- 敵は画面外周から **360° どこからでも完全ランダムにスポーン** して中央に向かう
- HUD は上下端に分離、中央のバトルフィールドを最大化
- **縦画面固定**（横画面非対応）

## 2. HUD（ヘッドアップディスプレイ）

### 2.1 上 HUD

| 要素 | 内容 |
|---|---|
| HP バー | 現在 HP / 最大 HP（リジェネ反映、ダメージ時シェイク） |
| 現 Tier | 例: `Tier 12` |
| 現ウェーブ | 例: `Wave 17 / 30`（次がエリート/ボスならアイコン強調） |

### 2.2 下 HUD（親指可動域）

| 要素 | 内容 |
|---|---|
| ネジ残高 | 現在保有数（獲得時はポップ演出） |
| アクティブボタン | 大きめのタップ領域、CD 中はクールタイム円グラフ |
| 速度切替ボタン | タップで `1x → 2x → 3x → 5x → 1x` をローテ。長押しで一時停止 / 解除 |
| 一時停止ボタン | 専用ボタン（速度切替長押しと等価、明示的なアイコン） |
| メニューボタン | メニューオーバーレイを開く（撤退 / 手動・自動切替 / 音量） |
| スクリーンセーバーボタン | タップでスクリーンセーバーダイアログ起動 |

## 3. マシンと敵の挙動

### 3.1 マシン（中央）

- 画面中央に固定、プレイヤーが移動操作することはない
- マシン本体 16 項目の値はラン開始時にスナップショット、ラン中ワークショップが乗算
- 索敵円は **常時 ON、薄く半透明** で表示（切替なし）

### 3.2 敵スポーン

- 画面外周から **完全ランダム** な角度でスポーン
- ウェーブ単位で出現数・出現密度が決まる（26 秒のウェーブタイマー）
- 過密時は **最大表示体数キャップ**、超過分は次フレーム以降に持ち越し
- エリート / ミニボス / Tier ボスは特別演出（フラッシュ + SE + 名前表示）

### 3.3 ウェーブ進行表示

- ウェーブ残り秒数はフィールド端の細い進捗バー
- 5/10/20/30 ウェーブが近いときバーの色を変える

## 4. 武器ごとの攻撃エフェクト概要

選択中の 1 種だけが描画される。共通の武器強化 Lv によりサイズ/速度/威力が成長する。

| 武器 | 描画概要 | 固有ステ反映 |
|---|---|---|
| Laser レーザー | 最寄りターゲットへ細い直線ビーム（軌跡 + ヒット時パーティクル） | 貫通数だけ後続敵を貫く |
| Cannon 大砲 | 着弾点を予告 → 着弾円範囲ダメ | 爆発半径が円サイズに反映 |
| Thunder サンダー | 同時 3 体に放電マークを出し DoT を継続 | 連鎖数だけ近隣に飛び火 |
| Cutter カッター | マシン周囲を回転するノコギリ刃 | 旋回半径と同時ヒット数が同時上昇 |

### アクティブスキル発動演出

- 全武器共通: 画面端からのエフェクト + 軽い震動 + サウンド
- Cutter の Overdrive 中は旋回速度 ×3 + 残像

> 具体的なフレーム数 / ヒットストップ / 画面振動の強度は claude design に委譲

## 5. 操作仕様

### 5.1 アクティブの発動

- **手動 / 自動** はメニュー内のトグルで切替（ラン中専用、ラン開始時は手動固定）
- 手動: アクティブボタンタップで即発動（CD 中はタップ不可）
- 自動: CD 明け次フレームで自動発動（手動タップは無効化）

### 5.2 一時停止

- 専用の一時停止ボタン or 速度切替ボタンを長押し
- 一時停止中もボトムシート操作とメニュー操作は可能

### 5.3 速度切替

- タップで `1x → 2x → 3x → 5x → 1x` ローテ
- スクリーンセーバー中は速度切替不可（タップで復帰）

### 5.4 ラン中ワークショップを開く

- 下 HUD のボトムシートハンドルをタップ or 上方向スワイプで開く
- 戦闘ロジックは **裏で進行継続**（一時停止しない）
- ボトムシート展開中も HUD 上段は視認可能

### 5.5 メニューを開く

- 下 HUD のメニューボタンタップでオーバーレイ
- メニュー項目:
  - 撤退（確認ダイアログ）
  - アクティブ手動 / 自動切替トグル
  - 音量調整（簡易）

### 5.6 スクリーンセーバー

- 下 HUD のスクリーンセーバーボタンタップで起動
- スクリーンセーバー中もゲームは進行（タイマー / 戦闘 / オートセーブ）
- 画面のどこかをタップで復帰
- 内容はゲームのトンマナに合った軽量アニメーション（具体は claude design）

## 6. ラン中ワークショップ UI

- 形式: 下からせり出すボトムシート
- 内容: 4 項目（攻撃力倍率 / 攻撃速度倍率 / HP 倍率 / ネジ獲得倍率）の強化カード
- 各カードの情報:
  - 現 Lv（例: `Lv 4`）
  - 現倍率（例: `×1.4`）
  - 次 Lv 倍率（例: `→ ×1.5`）
  - 必要ネジ数（不足時はグレーアウト）
- 強化ボタン: **+1 / +5 / Max** の 3 種
- 4 項目とも **ラン終了で全リセット** されることをシート上部に明記
- 詳細は [04-run-workshop.md](./04-run-workshop.md) 参照

## 7. リスタート / 撤退の扱い

| 操作 | 効果 |
|---|---|
| 撤退（メニュー → 撤退） | **確認ダイアログあり**。承認で即リザルトダイアログへ。獲得済みのボルト/超合金/パッチは **永続化される** |
| リスタート | 提供しない（同一ランをやり直す動線は持たない） |
| HP 0 でゲームオーバー | **確認なしで** リザルトダイアログへ。獲得済みは永続化、ネジは消滅 |

- 撤退・ゲームオーバーいずれもネジは消滅
- リザルトはダイアログ表示（独立画面ではない、バトル画面に重なる）

## 8. リザルトダイアログ

バトル終了時にバトル画面に重なって表示するダイアログ。

| 要素 | 内容 |
|---|---|
| ヘッダー | 「クリア」「全滅」「撤退」のいずれか |
| 統計 | 到達 Tier / 到達 Wave / 撃破数 / 所要時間 |
| 獲得 | ボルト / 超合金 / ドロップパッチ一覧 |
| アクション | 「タイトルへ」「出撃準備へ」ボタン |

## 9. アニメーション・フィードバック

- **被ダメージ**: HP バー赤フラッシュ + 画面に薄い赤ビネット
- **回復**: HP バー緑フェード
- **クリティカル**: 通常ダメ表記より大きく、色を変えて表示
- **ダメージ数値**: **毎ヒットごとにポップ**（過密時はスポーン体数キャップで対応）
- **獲得物**: ネジ / パッチドロップは HUD に吸い込まれる演出

> 具体的なアニメーション秒数 / イージング / 色は claude design に委譲
