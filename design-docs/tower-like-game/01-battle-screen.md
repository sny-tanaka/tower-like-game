# 01 — バトル画面 (Battle Screen)

ラン中、プレイヤーが実際に戦う画面。本作の体験の中心。片手スマホ操作で完結することを最優先とする。

**具体的なレイアウト・配色・余白・アニメーション秒数は claude design に委譲し、本章では情報設計（情報の種類・操作の種類・状態遷移）に専念する。**

---

## 1. 画面構成の概要

```
┌──────────────────────────────────────┐
│ [上 HUD: HP / Tier / Wave]              │  ← 上端固定
│                                      │
│              ▲ 敵                      │
│           ◇ 敵    ◇ 敵                   │
│                                      │
│        ◇          ★          ◇         │  ← ★ = マシン（中央固定）
│            (索敵円が常時表示)              │
│                                      │
│           ◇ 敵    ◇ 敵                   │
│              ▼ 敵                      │
│                                      │
│ [下 HUD: ネジ / アクティブ / 一時停止       │  ← 下端固定（親指帯）
│         / スクリーンセーバー]              │
└──────────────────────────────────────┘
```

- マシンは常に **画面中央固定**
- 敵は画面外周から **360° どこからでも完全ランダムにスポーン** して中央に向かう
- HUD は上下端に分離、中央のバトルフィールドを最大化
- **縦画面固定**（横画面非対応）

## 2. HUD（ヘッドアップディスプレイ）

### 2.1 上 HUD

| 要素 | 内容 |
|---|---|
| HP バー | 現在 HP / 最大 HP（リジェネ反映、ダメージ時シェイク） |
| 現 Tier | 例: `Tier 12` |
| 現ウェーブ | 例: `Wave 17 / 30`（次がエリート/ボスならアイコン強調） |

### 2.2 下 HUD（親指可動域）

| 要素 | 内容 |
|---|---|
| 通貨表示 | **ネジ残高 (`screw`, `size=lg`) と「ラン中獲得ボルト累計」 (`size=md`) を並列表示**。ラン獲得ボルトは `bolt - runStartBolt` を 0 以上にクランプした値で、 リザルトダイアログの `earnedBolt` と完全一致する。ネジ獲得時はポップ演出 |
| **武器切替アイコン × 4** | Laser / Cannon / Thunder / Cutter を常時表示、現装備をハイライト。タップで切替（CD 3 秒） |
| アクティブボタン | 現装備武器のアクティブ。大きめのタップ領域、CD 中はクールタイム円グラフ（ゲージは「発動 = 0 → 時計回りで満タンに溜まる」、ラン開始時はゲージ 0 = CD 満タンスタート） |
| 一時停止ボタン | 専用ボタン（明示的なアイコン）。**押下で「pause + メニュー開」が同時に行われる**。pause 状態とメニュー表示は完全同期し、`BattleMenuOverlay` を閉じると自動で pause も解除される。v0.2.0 で従来あった「メニュー専用ボタン」 は廃止し、本ボタンに統合した（v0.2.0 で速度切替ボタンも廃止） |
| スクリーンセーバーボタン | タップでスクリーンセーバーダイアログ起動 |

### 武器切替アイコンの表示状態

| 状態 | 表示 |
|---|---|
| 現装備武器 | ハイライト（強調表示） |
| 切替可能な武器 | 通常表示、タップ可能 |
| 切替 CD 中 | 全武器アイコンに CD 残り秒数（3 秒）の半透明オーバーレイ、タップ不可 |
| アクティブ CD 中の武器 | 武器アイコン下部に小さく CD バー（情報のみ、切替自体は CD と独立に可能） |

## 3. マシンと敵の挙動

### 3.1 マシン（中央）

- 画面中央に固定、プレイヤーが移動操作することはない
- マシン本体 16 項目の値はラン開始時にスナップショット、ラン中ワークショップが乗算
- 索敵円は **常時 ON、薄く半透明** で表示（切替なし）

### 3.2 敵スポーン

- 画面外周から **完全ランダム** な角度でスポーン
- ウェーブ単位で出現数・出現密度が決まる（通常ウェーブは 26 秒タイマー / 最終 W30 はカウントダウンせずボス撃破まで継続）
- 過密時は **最大表示体数キャップ**、超過分は次フレーム以降に持ち越し
- エリート / ミニボス / Tier ボスは spawn 時に **`AppearanceBannerFx`** を発火（`ELITE INCOMING` / `MINI BOSS INCOMING` / `TIER X BOSS` のフラッシュ + 名前バナー + SE）

### 3.3 ウェーブ進行表示

- 通常ウェーブ（W1〜W29）はウェーブ残り秒数をフィールド端の細い進捗バーで表示
- **最終ウェーブ W30 では進捗バーをカウントダウンしない**（ボス撃破がクリア条件）。バーは「BOSS」表示などに切替
- 5/10/20/30 ウェーブが近いときバーの色を変える

### 3.4 BATTLE START バナー

- ラン開始（`isRunActive` が **false → true に遷移したフレームのみ**）に `AppearanceBannerFx`（`kind: 'battle-start'`）を 1 度だけ発火
- BattleScreen の再マウントや wave 遷移では再発火しない（ちらつき防止）

### 3.5 敵接触ノックバック

- マシンに敵が触れた瞬間（**新規接触フレーム**）に敵を画面短辺の **5%**（≒ 400px 短辺で 20px 相当）だけ後方へ押し戻す
- 接触ダメージは継続接触中 `deltaSec` ベースで毎フレーム蓄積（ノックバックの再適用はしない）
- 連続接触時の過剰ノックバック・過剰ダメージを抑制する目的

## 4. 武器ごとの攻撃エフェクト概要

選択中の 1 種だけが描画される。共通の武器強化 Lv によりサイズ/速度/威力が成長する。

| 武器 | 描画概要 | 固有ステ反映 |
|---|---|---|
| Laser レーザー | 最寄りターゲットへ細い直線ビーム（軌跡 + ヒット時パーティクル） | 貫通数だけ後続敵を貫く |
| Cannon 大砲 | 着弾点を予告 → 着弾円範囲ダメ | 爆発半径が円サイズに反映 |
| Thunder サンダー | 同時 3 体に **独立した落雷** を落として DoT を継続（v0.2.0 で通常攻撃の連鎖は廃止） | 連鎖数はアクティブ Plasma Discharge にのみ反映 |
| Cutter カッター | マシン周囲を回転するノコギリ刃 | 旋回半径と同時ヒット数が同時上昇 |

### アクティブスキル発動演出

- 全武器共通: 画面端からのエフェクト + 軽い震動 + サウンド
- Cutter の Overdrive 中は旋回速度 ×3 + 残像

> 具体的なフレーム数 / ヒットストップ / 画面振動の強度は claude design に委譲

## 5. 操作仕様

### 5.1 アクティブの発動

- **手動 / 自動** はメニュー内のトグルで切替（ラン中専用、ラン開始時は手動固定）
- 手動: アクティブボタンタップで即発動（CD 中はタップ不可）
- 自動: CD 明け次フレームで自動発動（手動タップは無効化）
- **ラン開始時はゲージ 0 = CD 満タン状態**から始まり、`DEFAULT_ACTIVE_MAX_SEC`（= 60 秒）経過で初めて発動可能になる（出撃直後の即発動は不可）

### 5.2 一時停止とメニュー（統合）

- 専用の一時停止ボタンをタップすると **「pause 状態に入る」と「メニューオーバーレイ (`BattleMenuOverlay`) を開く」 が同時に実行される**（v0.2.0 で統合）
- メニューを閉じる（×ボタン or 背景タップ）と pause も自動解除されて戦闘が再開する
- pause 状態とメニュー表示の片方だけが立つ状況は存在しない（完全同期）
- v0.2.0 で「pause だけ・メニューだけ」 を独立にトグルする UI（メニュー専用ボタン）は廃止
- 一時停止中もボトムシート操作とメニュー内操作は可能

### 5.2.1 バックグラウンド自動 pause

- バトル画面マウント中は `document.visibilitychange` を listen し、`document.hidden === true` （= 画面が裏に回った）かつ **ラン中** であれば `setPaused(true)` を呼ぶ
- pause = メニュー開で同期しているため、復帰したときには `BattleMenuOverlay` が開いた状態で待機する
- **復帰時は自動再開しない**。ユーザーが明示的に「再開」 操作（メニューを閉じる等）をして初めて pause 解除 → ループ再開
- 目的: スマホで他アプリに移ったときに敵に殴られ続けるのを防ぐ

> v0.2.0 でゲームスピード切替（1x / 2x / 3x / 5x）機能は廃止。等速のみ。

### 5.3 ラン中ワークショップを開く

- 下 HUD のボトムシートハンドルをタップ or 上方向スワイプで開く
- 戦闘ロジックは **裏で進行継続**（一時停止しない）
- ボトムシート展開中も HUD 上段は視認可能

### 5.4 メニューの内容

- メニューは 5.2 の一時停止ボタンから開く（pause と完全同期、専用ボタンは廃止）
- メニュー項目:
  - 撤退（確認ダイアログ）
  - アクティブ手動 / 自動切替トグル
  - 音量調整（簡易）

### 5.5 スクリーンセーバー

- 下 HUD のスクリーンセーバーボタンタップで起動
- スクリーンセーバー中もゲームは進行（タイマー / 戦闘 / オートセーブ）
- 画面のどこかをタップで復帰
- 内容はゲームのトンマナに合った軽量アニメーション（具体は claude design）

## 6. ラン中ワークショップ UI

- 形式: 下からせり出すボトムシート
- 内容: 4 項目（攻撃力倍率 / 攻撃速度倍率 / HP 倍率 / ネジ獲得倍率）の強化カード
- 各カードの情報:
  - 現 Lv（例: `Lv 4`）
  - 現倍率（例: `×1.4`）
  - 次 Lv 倍率（例: `→ ×1.5`）
  - 必要ネジ数（不足時はグレーアウト）
- 強化ボタン: **+1 / +5 / Max** の 3 種
- 4 項目とも **ラン終了で全リセット** されることをシート上部に明記
- 詳細は [04-run-workshop.md](./04-run-workshop.md) 参照

## 7. リスタート / 撤退の扱い

| 操作 | 効果 |
|---|---|
| 撤退（メニュー → 撤退） | **確認ダイアログあり**。承認で即リザルトダイアログへ。獲得済みのボルト/超合金/パッチは **永続化される** |
| リスタート | 提供しない（同一ランをやり直す動線は持たない） |
| HP 0 でゲームオーバー | **確認なしで** リザルトダイアログへ。獲得済みは永続化、ネジは消滅 |

- 撤退・ゲームオーバーいずれもネジは消滅
- リザルトはダイアログ表示（独立画面ではない、バトル画面に重なる）

## 8. リザルトダイアログ

バトル終了時にバトル画面に重なって表示するダイアログ。

| 要素 | 内容 |
|---|---|
| ヘッダー | 「クリア」「全滅」「撤退」のいずれか |
| 統計 | 到達 Tier / 到達 Wave / 撃破数 / 所要時間 |
| 獲得 | ボルト / 超合金 / ドロップパッチ一覧 |
| アクション | 「タイトルへ」「出撃準備へ」ボタン |

## 9. アニメーション・フィードバック

- **被ダメージ**: HP バー赤フラッシュ + 画面に薄い赤ビネット
- **回復**: HP バー緑フェード
- **クリティカル**: 通常ダメ表記より大きく、色を変えて表示
- **ダメージ数値**: **毎ヒットごとにポップ**（過密時はスポーン体数キャップで対応）
- **獲得物**: ネジ / パッチドロップは HUD に吸い込まれる演出

> 具体的なアニメーション秒数 / イージング / 色は claude design に委譲
