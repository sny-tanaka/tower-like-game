# 01 — バトル画面 (Battle Screen)

ラン中、プレイヤーが実際に戦う画面。本作の体験の中心であり、片手スマホ操作で完結することを最優先とする。

---

## 1. 画面構成の概要

```
┌──────────────────────────────────────┐
│ [HUD 上段: HP / Tier / Wave / 速度]     │  ← 上端固定
│                                      │
│              ▲ 敵                      │
│           ◇ 敵    ◇ 敵                   │
│                                      │
│        ◇          ★          ◇         │  ← ★ = マシン（中央固定）
│            (索敵円が薄く表示)              │
│                                      │
│           ◇ 敵    ◇ 敵                   │
│              ▼ 敵                      │
│                                      │
│ [HUD 下段: ネジ / アクティブ CD / 設定]  │  ← 下端固定（親指帯）
└──────────────────────────────────────┘
```

- マシンは常に **画面中央固定**。
- 敵は画面外周から **360° どこからでも** スポーンして中央に向かって接近する。
- HUD は上下端に分離し、中央のバトルフィールドを最大化する。

## 2. HUD（ヘッドアップディスプレイ）

### 2.1 上段 HUD

| 要素 | 内容 |
|---|---|
| HP バー | 現在 HP / 最大 HP、リジェネ反映、ダメージ時シェイク |
| 現 Tier | 例: `Tier 12` |
| 現ウェーブ | 例: `Wave 17 / 30`、次がエリート/ボスならアイコン強調 |
| 速度倍率表示 | `x1 / x2 / x3 / x5 / ⏸` のうち現在値 |
| 撤退ボタン | タップでリザルトへ（確認モーダル経由） |

### 2.2 下段 HUD（親指可動域）

| 要素 | 内容 |
|---|---|
| ネジ残高 | 現在保有数。獲得時はポップアップ加算演出 |
| アクティブボタン | 大きめのタップ領域。CD 中はクールタイム円グラフを重ねる |
| 速度切替ボタン | 1 タップで次倍率へローテ、長押しで一時停止 |
| ワークショップボタン | ラン中ワークショップのボトムシートを開く |
| 設定 / 撤退メニュー | 小アイコンに集約 |

> TBD: 各ボタンのタップ領域サイズ（最小 44pt 目標）、ジェスチャ詳細（ダブルタップ、スワイプ等の割当）。

## 3. マシンと敵の挙動

### 3.1 マシン（中央）

- 画面中央に固定。プレイヤーが移動操作することはない。
- マシン本体 16 項目（HP / 攻撃 / 索敵 等）の値は、ラン開始時にスナップショットされ、ラン内ワークショップでさらに乗算される。
- 索敵円は **薄く半透明** で表示し、武器の届く距離感を視覚化する（ON/OFF 切替は TBD）。

### 3.2 敵スポーン

- 画面外周のリングから 360° 均等にスポーン候補が発生。
- ウェーブ単位で出現数・出現密度が決まり、26 秒のウェーブタイマーで進行。
- エリート / ミニボス / Tier ボスは、ウェーブ目に応じて特別演出（フラッシュ + 効果音 + 名前表示）を伴って登場。

> TBD: スポーン角度の偏りロジック（完全ランダム / セクター制御）、画面外マージン量。

### 3.3 ウェーブ進行表示

- ウェーブの残り秒数は HUD ではなく、フィールド端の細い進捗バーで暗示する（HUD を過密にしない）。
- 次のミルストーン（5/10/20/30 ウェーブ目）が近いときはバーの色を変える。

## 4. 武器ごとの攻撃エフェクト概要

選択中の 1 種だけが描画される。1 本化 Lv によりサイズ/速度/威力が成長する。

| 武器 | 描画概要 | 固有ステ反映 |
|---|---|---|
| Bow 弓 | 索敵した最遠の単体へ直線弾（軌跡 + ヒット時パーティクル） | 貫通数だけ後続敵を貫く |
| Cannon 大砲 | 着弾点を予告 → 着弾円範囲ダメ | 爆発半径が円サイズに反映 |
| Tome 魔導書 | 同時 3 体に魔法陣を出し DoT を継続 | 連鎖数だけ近隣に飛び火 |
| Blades 双剣 | マシン周囲を旋回する刃 2 本 | 旋回半径と同時ヒット数が同時上昇 |

### アクティブスキル発動演出

- 全武器共通で **画面端からのエフェクト + 軽い震動 + サウンド**。
- Blades の「乱舞」中は旋回速度 ×3 + 残像。

## 5. 操作仕様

### 5.1 アクティブの発動

- 設定で **手動 / 自動** を切替可能（`09-ui-screens.md` 設定画面参照）。
- 手動: 下段アクティブボタンタップで即時発動（CD 中はタップ不可）。
- 自動: CD 明け次フレームで自動発動。手動タップは無効化される（誤操作防止）。

### 5.2 一時停止

- 下段の速度切替ボタンを **長押し** で一時停止 / 解除。
- 一時停止中は HUD のみ反応、戦闘ロジックは完全停止。

### 5.3 速度切替

- タップで `x1 → x2 → x3 → x5 → x1` をローテ。
- 速度値はラン中ワークショップ等の演出時間にも反映する。

### 5.4 ラン中ワークショップを開く

- 下段のワークショップボタンで **ボトムシート** が立ち上がる。
- 戦闘ロジックは **裏で進行継続**（一時停止しない）。
- ボトムシート展開中も HUD 上段は視認可能なレイアウトを維持する。

> TBD: ボトムシート展開中の半透明オーバーレイ濃度、スワイプダウンで閉じる挙動。

## 6. ラン中ワークショップ UI

- 形式: 下からせり出すボトムシート。
- 内容: 4 項目（攻撃力倍率 / 攻撃速度倍率 / HP 倍率 / ネジ獲得倍率）の強化カード。
- 各カードに次の情報を載せる:
  - 現在 Lv（例: `Lv 4`）
  - 現在倍率（例: `×1.4`）
  - 次 Lv の倍率（例: `→ ×1.5`）
  - 必要ネジ数（不足時はグレーアウト）
- 強化ボタンタップで即時反映、ネジ減算演出 + カードの値が更新。
- 4 項目とも **ラン終了で全リセット** されることをシート上部に明記する。

> TBD: ネジコストカーブ、4 項目それぞれの Lv 上限の有無、カードの並び順。

## 7. リスタート / 撤退の扱い

| 操作 | 効果 |
|---|---|
| 撤退（メニュー → 撤退） | 即座にリザルトへ。獲得済みのボルト/超合金/パッチは **永続化される** |
| リスタート | 提供しない（同一ランをやり直す動線は持たない） |
| HP 0 でゲームオーバー | リザルトへ。撤退と同様に永続化される |

- 撤退・ゲームオーバーいずれの場合も **ネジは消滅** する。
- リザルト画面の仕様は `09-ui-screens.md` を参照。

> TBD: 撤退時の確認モーダル文言、ゲームオーバー時の追加演出。

## 8. アニメーション・フィードバック

- **被ダメージ**: マシン HP バーが赤くフラッシュ + 画面に薄い赤ビネット。
- **回復**: HP バーが緑にフェード。
- **クリティカル**: 通常ダメージ表記より大きく、色を変えて表示。
- **獲得物**: ネジ / パッチドロップは小さなアイコンが HUD まで吸い込まれる演出。
