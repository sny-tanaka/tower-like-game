# Tower Like Game ゲーム仕様

[THE TOWER - Idol Tower Defence](../the-tower/) をオマージュした個人開発 PWA タワーディフェンスゲームの仕様書。

- 営利目的ではない個人プロジェクト
- スマホ片手操作前提、ブラウザ動作
- データは IndexedDB に保存（サーバなし）

## このドキュメントの読み方

- 各章は `TBD:` 接頭辞付きで未確定の数値・詳細を明示しています
- 章ごとに独立して読めるよう、用語と決定事項は冒頭に再掲しています
- 実装と並行して各章の TBD を埋めていく運用

## 設計の核（一文要約）

> **「マシン本体 + 武器 + パッチ の 3 層装備カスタマイズで、Tier 無限の動的タワーディフェンスを攻略する」**

## 本家との主な差分

### 削るもの

- BOT / ガーディアン / モジュール 4 部位 / 究極の武器 9 種
- トーナメント / ギルド / ストア / 課金 / リアルマネー
- 通貨 13 種 → 3 種に圧縮
- 固定 Tier 16 段階 → 動的 Tier ∞
- ラン中ドラフト（カード 3 択）→ ラン中ワークショップ（ネジで Lv 上げ）

### 足すもの

- **武器装備の概念**：マシンに 1 つ武器を装備、武器種で通常攻撃挙動と固有ステが変わる
- **武器のアクティブスキル**：手動 / 自動 切替可能
- **パッチ（パッシブ装備）**：同 Tier 2 個合成で Tier UP、強化通貨を使わない
- **武器固有ステ**：貫通数 / 爆発半径 / 連鎖数 / 旋回半径 を武器ごとに割り当て
