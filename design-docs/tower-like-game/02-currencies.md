# 02 — 通貨 (Currencies)

本作は **3 種類の通貨** を用いる。1 つはラン内専用、2 つは永続化される。
レアリティ概念を持たないパッチは合成のみで成長するため、**強化通貨はパッチには紐づかない**。

---

## 1. 通貨の早見表

| 通貨 | 表記 | スコープ | 主な用途 | ラン終了時の挙動 |
|---|---|---|---|---|
| ネジ | Screw | **ラン内のみ** | ラン中ワークショップ 4 項目の強化 | **すべて消滅** |
| ボルト | Bolt | 永続 | マシン本体 16 項目の強化 | 残高に加算される（永続化） |
| 超合金 | Alloy | 永続 | 武器 4 種の 1 本化 Lv 強化 | 残高に加算される（永続化） |

- パッチは「通貨を使って強化する」概念を持たない。`05-patches.md`（TBD）参照。
- 通貨は **負数にならない**。獲得・消費どちらも整数で扱う（小数を持たない）。

> TBD: 通貨の最大保有数の上限、表示単位（K / M / B などの省略表記）。

## 2. 各通貨の入手元

源（ソース）と通貨の対応を表で示す。`◯` = 主な入手元、`△` = 条件付き / 控えめに入手、`×` = 入手なし。

| 入手元 | ネジ | ボルト | 超合金 |
|---|:--:|:--:|:--:|
| 通常敵 撃破 | ◯ | × | × |
| エリート 撃破（5W ごと） | ◯ | △ | × |
| ウェーブクリア報酬 | ◯ | × | × |
| ミニボス（10W / 20W） | ◯ | ◯ | △ |
| Tier ボス（30W） | ◯ | ◯ | ◯ |
| 章（= Tier）クリア報酬 | × | ◯ | ◯ |

### 補足

- **ネジは全ソースから出る** が、出るのはラン中だけ。獲得した瞬間からラン中ワークショップで即時利用できる。
- **ボルト**は主にミニボス以降から本格的に入る。通常敵からはドロップしない（雑魚処理を「お金集め」ではなくテンポ維持に振る意図）。
- **超合金** は最も希少。Tier ボスと Tier クリア報酬が主なソース。ミニボスでも極小量。

> TBD: 各ソースの基礎ドロップ量（例: 通常敵 Tier1 で 1 ネジ / 撃破）。
> TBD: ボルト・超合金を「敵から直接ドロップさせる」のか「リザルトで集計付与」とするかの整理。

## 3. 各通貨の用途詳細

### 3.1 ネジ (Screw)

- 使い道: **ラン中ワークショップの 4 項目** に限定
  - 攻撃力倍率（×1.0 → +0.1 / Lv）
  - 攻撃速度倍率（×1.0 → +0.1 / Lv）
  - HP 倍率（×1.0 → +0.1 / Lv）
  - ネジ獲得倍率（×1.0 → +0.1 / Lv）
- 強化は **乗算バフ**。マシン本体側のステに後段で掛かる。
- ラン終了時に **残高 0 にリセット**。永続化されない。
- 入手時にマシンの「ネジ獲得倍率」（マシン本体 16 項目の 1 つ）× ラン内ワークショップの「ネジ獲得倍率」が掛かる。

> TBD: 各項目の Lv ごとのコストカーブ（base × growth^Lv のパラメータ）、Lv 上限の有無。

### 3.2 ボルト (Bolt)

- 使い道: **マシン本体 16 項目** の永続強化
  - Defensive: 最大 HP / HP リジェネ/秒 / 被ダメ軽減 / 防御力
  - Offensive: 基礎攻撃力 / 攻撃速度 / 索敵距離 / クリ率 / クリ倍率
  - Active: アクティブ威力 / アクティブ CD 減少
  - Economic: ネジ獲得倍率 / ボルト獲得倍率 / 超合金獲得倍率 / パッチドロップ率
  - Slot: パッチスロット数（1 → 6）
- Lv 上限なし（パッチスロット数のみ 6 で上限）。
- コスト = `base × growth^Lv`（項目ごとにパラメータが異なる）。
- ラン中に獲得した分はリザルトで永続残高に合算される。

> TBD: 16 項目それぞれの `base` と `growth`、初期残高、開始時保有スロット数（1 想定）。

### 3.3 超合金 (Alloy)

- 使い道: **4 武器それぞれの「1 本化 Lv」** の強化
  - Bow / Cannon / Tome / Blades の **4 系統に別残高ではなく共有残高**（プレイヤーが任意に振り分け）。
  - 1 本化 Lv を上げると、その武器の「基礎ダメ / 攻撃速度 / アクティブ威力 / 固有ステ」が同時に伸びる。
- Lv 上限なし。
- 4 武器とも最初から開放済み（解放コスト不要）。

> TBD: 1 武器あたりのコストカーブ、Lv ごとの伸び率、固有ステの上昇カーブ。

## 4. 永続化フロー

```
[ラン中] ─ 獲得 ─▶ [ラン内残高: Screw / Bolt / Alloy]
                                │
                                │ リザルトで集計
                                ▼
[ラン終了]
     ├─ Screw         → 破棄（消滅）
     ├─ Bolt          → メタ残高に加算 → IndexedDB 保存
     └─ Alloy         → メタ残高に加算 → IndexedDB 保存

[次ラン開始]
     ├─ Screw         → 0 から開始
     ├─ Bolt / Alloy  → メタ残高をそのまま継続
     └─ パッチ         → メタ側の所持パッチからスロットへ装着
```

- リザルトでは **獲得量と加算後残高の両方** を表示する（プレイヤーが進行感を掴みやすくする）。
- 撤退・ゲームオーバーでも永続化処理は同様（ネジは消滅、ボルト/超合金は加算）。

> TBD: 「ラン中に獲得したボルト/超合金は確定でリザルトまで保持されるか」「途中でブラウザクラッシュした場合の取り扱い」。

## 5. 通貨倍率の計算順（合意済みの方針）

ネジを例に、最終獲得量は概ね以下の積で求まる:

```
取得ネジ = (源の基礎値)
        × (マシン本体: ネジ獲得倍率)
        × (ラン中ワークショップ: ネジ獲得倍率)
        × (Tier 補正)            ← TBD
        × (パッチ補正)            ← TBD
```

- ボルト / 超合金も同様に、マシン本体側の「ボルト獲得倍率」「超合金獲得倍率」が掛かる。
- ラン中ワークショップで倍率が乗るのは **ネジのみ**（仕様サマリーの 4 項目）。

## 6. UI 上の表示ルール

- ネジ: バトル画面 HUD 下段に常時表示。永続画面では表示しない（ラン外では存在しないため）。
- ボルト: メタ進行画面（マシン強化）でヘッダー表示。
- 超合金: メタ進行画面（武器庫）でヘッダー表示。
- リザルト画面では 3 通貨すべてを集計表示する。

> TBD: 各通貨のアイコン、色、フォントウェイトの統一ルール。

## 7. まとめ

- **ネジは「ラン中のテンポを買う通貨」**。残らないのでガンガン使う。
- **ボルトは「マシンを底上げする通貨」**。16 項目に薄く広く投資して長期で伸ばす。
- **超合金は「武器を尖らせる通貨」**。希少なため使う武器に集中させるのが基本。
