# 02. 通貨設計

本作の経済は **ラン内通貨 1 + 永続通貨 2** の計 3 通貨で構成する。

## 1. 通貨の早見表

| 通貨 | 英表記 | 範囲 | 主な用途 | ラン終了時の挙動 |
|---|---|---|---|---|
| ネジ | Screw | **ラン内のみ** | ラン中ワークショップ 4 項目の強化 | **すべて消滅** |
| ボルト | Bolt | 永続 | マシン本体 16 項目の永続強化 | 残高に加算される（永続化） |
| 超合金 | Alloy | 永続 | 全武器共通の武器強化 Lv の強化 | 残高に加算される（永続化） |

- パッチは「通貨を使って強化する」概念を持たない（同 Tier 2 個合成のみ）。`06-patches.md` 参照。
- パッチ自体はドロップで入手し、合成で Tier UP する（通貨枠ではない）。

## 2. 各通貨の入手元

### ベースドロップ表（T1W1 想定）

| 入手元 | ネジ | ボルト | 超合金 | パッチ |
|---|---|---|---|---|
| 通常 Standard 撃破 | 1 | 50% で 1 | × | × |
| 通常 Swift 撃破 | 2 | 50% で 2 | × | × |
| 通常 Tough 撃破 | 5 | 50% で 5 | × | × |
| エリート 撃破（W5/W15/W25） | 10 | 確定 10 | 30% で 1 | 1% でドロップ |
| ミニボス（W10/W20） | 50 | 確定 50 | 確定 1 | 5% でドロップ |
| Tier ボス（W30） | 250 | 確定 250 | 確定 5 | 20% でドロップ |
| Tier クリア報酬 | × | × | × | × |

> **ネジは自動取得**: マシンは盤面中央に固定で移動しないため、ネジは撃破時に瞬時に加算される（マグネット効果は不要）。
> **Tier クリア報酬は廃止**: Tier ボス撃破ドロップに統合（同じ「Tier 終了時の見返り」を 2 か所に分けない）。
> **ボルト・超合金もリアルタイム付与**: ドロップした瞬間に HUD の残高に加算。途中撤退してもその時点までの分は確定。

### Tier 進行スケール

| 通貨 | Tier 進行倍率 |
|---|---|
| ネジ / ボルト / 超合金 | **×T²** |

代表 Tier の倍率:

| Tier | 倍率 |
|---:|---:|
| 1 | ×1 |
| 2 | ×4 |
| 5 | ×25 |
| 10 | ×100 |
| 20 | ×400 |
| 50 | ×2,500 |

> 敵 HP は ×1.8^(T-1) でより急峻に伸びるため、プレイヤーは永続強化 Lv を上げないと釣り合わない（Tier 進行に対して指数的な強化投資が必要）。
> パッチドロップ率は **Tier 進行で増加しない**（ベース確率にマシン「パッチドロップ率倍率」のみ乗算）。

## 3. 各通貨の用途詳細

### 3.1 ネジ (Screw)

- 使い道: **ラン中ワークショップの 4 項目**（→ [04-run-workshop.md](./04-run-workshop.md)）
  - 攻撃力倍率 / 攻撃速度倍率 / HP 倍率 / ネジ獲得倍率
- 強化は **乗算バフ**、マシン本体ステに乗算
- ラン終了時に **残高 0 にリセット**
- 入手量計算式:

```
取得ネジ = ソース基礎値 × T² × マシン「ネジ獲得倍率」× RW「ネジ獲得倍率」× パッチ補正
```

### 3.2 ボルト (Bolt)

- 使い道: **マシン本体 16 項目**（→ [03-machine.md](./03-machine.md)）
  - Defensive: 最大 HP / HP リジェネ/秒 / 被ダメ軽減 / 防御力
  - Offensive: 基礎攻撃力 / 攻撃速度 / 索敵距離 / クリ率 / クリ倍率
  - Active: アクティブ威力 / アクティブ CD 減少
  - Economic: ネジ獲得倍率 / ボルト獲得倍率 / 超合金獲得倍率 / パッチドロップ率倍率
  - Slot: パッチスロット数（1 → 6）
- Lv 上限なし（パッチスロット数のみ Lv 5 で打ち止め）
- コストカーブは項目別に [03-machine.md](./03-machine.md) を参照
- 入手量計算式:

```
取得ボルト = ソース基礎値 × T² × マシン「ボルト獲得倍率」× パッチ補正
```

### 3.3 超合金 (Alloy)

- 使い道: **全武器共通の「武器強化 Lv」** の強化（1 系統のみ）
  - 武器ごとの個別 Lv は持たない。**1 つの Lv を上げると Laser / Cannon / Thunder / Cutter の 4 武器すべての数値が同時に伸びる**
  - 「育てた武器以外を使わなくなる」事態を防ぐ
  - Lv が上がると各武器の「基礎ダメ倍率 / 攻撃速度 / アクティブ威力 / 固有ステ」が同時に伸びる
- Lv 上限なし
- 4 武器とも最初から開放済み（解放コスト不要）
- コストカーブ: `ceil(200 × 1.12^Lv)`。詳細は [05-weapons.md](./05-weapons.md)
- 入手量計算式:

```
取得超合金 = ソース基礎値 × T² × マシン「超合金獲得倍率」× パッチ補正
```

## 4. 永続化フロー

```
[ラン中] 敵撃破 / ボス撃破
    │
    ├─ ネジ           → ラン中ワークショップで即時消費可能
    │
    ├─ ボルト         → リアルタイムで HUD 加算 → ラン終了時に永続残高へ確定
    │
    ├─ 超合金         → リアルタイムで HUD 加算 → ラン終了時に永続残高へ確定
    │
    └─ パッチ         → メタ側の所持パッチに即時追加（合成元として使用可能）
```

- 撤退・ゲームオーバーでも永続化処理は同様（ネジは消滅、ボルト/超合金/パッチは確定）

## 5. 通貨倍率の計算順

ネジを例に、最終獲得量は概ね以下の積で求まる:

```
取得ネジ = ソース基礎値
        × Tier 倍率 (T²)
        × マシン「ネジ獲得倍率」（線形 +0.03/Lv、初期 ×1.0）
        × ラン中ワークショップ「ネジ獲得倍率」（+0.1/Lv、初期 ×1.0）
        × パッチ補正（「ボーナスドロップ」が稀に ×2）
```

- ボルト・超合金にはラン中ワークショップ倍率は **掛からない**（ネジ専用）
- パッチによる経済補正は **上限なし**

## 6. UI 上の表示ルール

- ネジ: バトル画面 HUD 下段に常時表示。永続画面では表示しない（ラン外では存在しないため）
- ボルト: ホーム / マシン強化 / バトル画面の HUD 上段に表示
- 超合金: ホーム / 武器庫 / バトル画面の HUD 上段に表示
- 数値表示の単位切替: **1,000 以上で K**、1,000,000 以上で M、以降 B / T / Q / s / S ...

| 内部値 | 表示 |
|---:|---:|
| 999 | 999 |
| 1,000 | 1.00K |
| 1,234 | 1.23K |
| 12,345 | 12.3K |
| 1,234,567 | 1.23M |

- 切り捨て表示（小数点 2 桁）

## 7. まとめ

- **ネジは「ラン中のテンポを買う通貨」**。残らないのでガンガン使う
- **ボルトは「マシン本体の長期成長を買う通貨」**。1 Tier 進めるごとに ×T² ずつ稼ぎが伸びる
- **超合金は「全武器を一斉に底上げする通貨」**。少なめのドロップ率を長期で集めて武器強化 Lv に投資
