# 02. 通貨設計

本作の経済は **ラン内通貨 1 + 永続通貨 2** の計 3 通貨で構成する。

## 1. 通貨の早見表

| 通貨 | 英表記 | 範囲 | 主な用途 | ラン終了時の挙動 |
|---|---|---|---|---|
| ネジ | Screw | **ラン内のみ** | ラン中ワークショップ 4 項目の強化 | **すべて消滅** |
| ボルト | Bolt | 永続 | マシン本体 16 項目の永続強化 | 残高に加算される（永続化） |
| 超合金 | Alloy | 永続 | 全武器共通の武器強化 Lv の強化 | 残高に加算される（永続化） |

- パッチは「通貨を使って強化する」概念を持たない（同 Tier 2 個合成のみ）。`06-patches.md` 参照。
- パッチ自体はドロップで入手し、合成で Tier UP する（通貨枠ではない）。

## 2. 各通貨の入手元

### ベースドロップ表（T1W1 想定）

| 入手元 | ネジ | ボルト | 超合金 | パッチ |
|---|---|---|---|---|
| 通常 Standard 撃破 | 1 | 50% で 1 | × | × |
| 通常 Swift 撃破 | 2 | 50% で 2 | × | × |
| 通常 Tough 撃破 | 5 | 50% で 5 | × | × |
| エリート 撃破（W5/W15/W25） | 10 | 確定 10 | 30% で 1 | 1% でドロップ |
| ミニボス（W10/W20） | 50 | 確定 50 | 確定 1 | 5% でドロップ |
| Tier ボス（W30） | 250 | 確定 250 | 確定 5 | 20% でドロップ |
| Tier クリア報酬 | × | × | × | × |

> **ネジは自動取得**: マシンは盤面中央に固定で移動しないため、ネジは撃破時に瞬時に加算される（マグネット効果は不要）。
> **Tier クリア報酬は廃止**: Tier ボス撃破ドロップに統合（同じ「Tier 終了時の見返り」を 2 か所に分けない）。
> **ボルト・超合金もリアルタイム付与**: ドロップした瞬間に HUD の残高に加算。途中撤退してもその時点までの分は確定。

### Tier 進行スケール

| 通貨 | Tier 進行倍率 | Wave 進行倍率 |
|---|---|---|
| ネジ | `tierScrewFactor(T) = 1.5^(T-1)` | `waveScrewFactor(W) = 1 + 0.2 × (W-1)` |
| ボルト / 超合金 | **hybrid: T≤3 で `T²`、T≥4 で `9 × 2.25^(T-3)`** | （なし） |

代表 Tier の倍率（ボルト / 超合金 = hybrid スケール）:

| Tier | 倍率 | 1 段あたり比率 |
|---:|---:|---:|
| 1 | ×1 | — |
| 2 | ×4 | 4.00 |
| 3 | ×9 | 2.25 |
| 4 | ×20.25 | 2.25 |
| 5 | ×45.56 | 2.25 |
| 10 | ×2,627 | 2.25 |
| 20 | ×8.74e6 | 2.25 |

> **設計意図（v1.5.0）**: 旧 `×T²` は Tier 上昇 1 段あたりの倍率が漸減 (4→2.25→1.78→1.56…) し、敵 HP の伸び (1.8×/T) を T4 以降下回るため、Tier を進めるほど相対的に貧乏になる問題があった。T4 以降を 2.25× 固定にすることで、現行 T2→T3 の最大旨味比率（9/4 = 2.25）を恒久化し、敵 HP 1.8×/T に対して報酬 2.25×/T = 毎 Tier の実質購買力 +25% を維持する。T1〜T3 の値は旧式と完全一致するため既存バランスは保たれる。

代表値の参考（ネジ）:

| Tier | tierScrewFactor | W=1 | W=15 | W=30 |
|---:|---:|---:|---:|---:|
| 1 | ×1.00 | ×1.0 | ×3.8 | ×6.8 |
| 5 | ×5.06 | ×5.1 | ×19.2 | ×34.4 |
| 10 | ×38.4 | ×38.4 | ×146 | ×261 |

> 敵 HP は ×1.8^(T-1) でより急峻に伸びるため、プレイヤーは永続強化 Lv を上げないと釣り合わない（Tier 進行に対して指数的な強化投資が必要）。
> パッチドロップ率は **Tier 進行で増加しない**（ベース確率にマシン「パッチドロップ率倍率」のみ乗算）。

## 3. 各通貨の用途詳細

### 3.1 ネジ (Screw)

- 使い道: **ラン中ワークショップの 4 項目**（→ [04-run-workshop.md](./04-run-workshop.md)）
  - 攻撃力倍率 / 攻撃速度倍率 / HP 倍率 / ネジ獲得倍率
- 強化は **乗算バフ**、マシン本体ステに乗算
- ラン終了時に **残高 0 にリセット**
- 入手量計算式（v0.2.0 で wave / tier の progression スケール係数を追加）:

```
取得ネジ = ソース基礎値
        × waveScrewFactor(W)         // 1 + 0.2 × (W - 1)
        × tierScrewFactor(T)         // 1.5 ^ (T - 1)
        × マシン「ネジ獲得倍率」
        × RW「ネジ獲得倍率」
        × パッチ補正
```

- **`waveScrewFactor(W) = 1 + 0.2 × (W - 1)`** — wave 1 で ×1.0、wave 30 で ×6.8
- **`tierScrewFactor(T) = 1.5 ^ (T - 1)`** — Tier 1 で ×1.0、Tier 5 で ×5.06、Tier 10 で ×38.4
- 通常 / 上位敵（エリート / ミニボス / Tier ボス）すべてに乗算
- ボルト・超合金には wave / tier スケールは適用しない（ネジ専用）

### 3.2 ボルト (Bolt)

- 使い道: **マシン本体 16 項目**（→ [03-machine.md](./03-machine.md)）
  - Defensive: 最大 HP / HP リジェネ/秒 / 被ダメ軽減 / 防御力
  - Offensive: 基礎攻撃力 / 攻撃速度 / 索敵距離 / Critical率 / Critical倍率
  - Active: アクティブ威力 / アクティブ CD 減少
  - Economic: ネジ獲得倍率 / ボルト獲得倍率 / 超合金獲得倍率 / パッチドロップ率倍率
  - Slot: パッチスロット数（1 → 6）
- Lv 上限なし（パッチスロット数のみ Lv 5 で打ち止め）
- コストカーブは項目別に [03-machine.md](./03-machine.md) を参照
- 入手量計算式:

```
取得ボルト = ソース基礎値 × tierScale(T) × マシン「ボルト獲得倍率」× パッチ補正

ここで tierScale(T) =
  T ≤ 3 : T²
  T ≥ 4 : 9 × 2.25^(T-3)
```

### 3.3 超合金 (Alloy)

- 使い道: **全武器共通の「武器強化 Lv」** の強化（1 系統のみ）
  - 武器ごとの個別 Lv は持たない。**1 つの Lv を上げると Laser / Cannon / Thunder / Cutter の 4 武器すべての数値が同時に伸びる**
  - 「育てた武器以外を使わなくなる」事態を防ぐ
  - Lv が上がると各武器の「基礎ダメ倍率 / 攻撃速度 / アクティブ威力 / 固有ステ」が同時に伸びる
- Lv 上限なし
- 4 武器とも最初から開放済み（解放コスト不要）
- コストカーブ: `ceil(200 × 1.12^Lv)`。詳細は [05-weapons.md](./05-weapons.md)
- 入手量計算式:

```
取得超合金 = ソース基礎値 × tierScale(T) × マシン「超合金獲得倍率」× パッチ補正

ここで tierScale(T) =
  T ≤ 3 : T²
  T ≥ 4 : 9 × 2.25^(T-3)
```

## 4. 永続化フロー

```
[ラン中] 敵撃破 / ボス撃破
    │
    ├─ ネジ           → ラン中ワークショップで即時消費可能
    │
    ├─ ボルト         → リアルタイムで HUD 加算 → ラン終了時に永続残高へ確定
    │
    ├─ 超合金         → リアルタイムで HUD 加算 → ラン終了時に永続残高へ確定
    │
    └─ パッチ         → メタ側の所持パッチに即時追加（合成元として使用可能）
```

- 撤退・ゲームオーバーでも永続化処理は同様（ネジは消滅、ボルト/超合金/パッチは確定）

## 5. 通貨倍率の計算順

ネジを例に、最終獲得量は概ね以下の積で求まる:

```
取得ネジ = ソース基礎値
        × waveScrewFactor(W)              // 1 + 0.2 × (W - 1)
        × tierScrewFactor(T)              // 1.5 ^ (T - 1)
        × マシン「ネジ獲得倍率」（線形 +0.03/Lv、初期 ×1.0）
        × ラン中ワークショップ「ネジ獲得倍率」（+0.1/Lv、初期 ×1.0）
        × パッチ補正（「ボーナスドロップ」が稀に ×2）
```

- ボルト・超合金には **ラン中ワークショップ倍率も wave/tier の screw スケールも掛からない**（ネジ専用）。ボルト / 超合金は hybrid `tierScale(T)`（T≤3 は `T²`、T≥4 は `9 × 2.25^(T-3)`）
- パッチによる経済補正は **上限なし**

## 6. UI 上の表示ルール

- ネジ: バトル画面 HUD 下段に常時表示。永続画面では表示しない（ラン外では存在しないため）
- ボルト: ホーム / マシン強化 / バトル画面の HUD 上段に表示
- 超合金: ホーム / 武器庫 / バトル画面の HUD 上段に表示
- 数値表示の単位切替: **アルファベット表記**（大文字 A-Z、無限スケール対応）
- 単位は 1,000 倍ごとに 1 段階繰り上がる
  - 1,000 以上 → A
  - 1,000,000 以上 → B
  - 10^9 以上 → C
  - ... 10^78 以上 → Z
  - 10^81 以上 → AA
  - 10^84 以上 → AB
  - ... → AZ → BA → BB → ...（Excel カラム名と同じ繰り上がり方）

| 内部値 | 表示 |
|---:|---:|
| 999 | 999 |
| 1,000 | 1.00A |
| 1,234 | 1.23A |
| 12,345 | 12.3A |
| 1,234,567 | 1.23B |
| 9.99 × 10^77 | 999Z |
| 1.00 × 10^78 | 9.99Z（次へ繰り上げ） |
| 1.00 × 10^81 | 1.00AA |

- **切り捨て表示**（小数点 2 桁）
- 内部値は浮動小数で保持、表示時のみアルファベット変換
- 27 段目以降は 2 文字 / 53 段目以降は 3 文字（理論上無限）

### 単位文字の決定式

```
n 段目（1,000^n に対応する単位、n ≥ 1）:
  1 文字: n = 1〜26（A=1, B=2, ..., Z=26）
  2 文字: n = 27〜702（AA=27, AB=28, ..., AZ=52, BA=53, ..., ZZ=702）
  3 文字: n = 703〜...

カラム名計算（n から文字列を求める）:
  s = ""
  while n > 0:
    n -= 1
    s = chr(65 + n % 26) + s
    n //= 26
  return s
```

## 7. まとめ

- **ネジは「ラン中のテンポを買う通貨」**。残らないのでガンガン使う
- **ボルトは「マシン本体の長期成長を買う通貨」**。1 Tier 進めるごとに ×2.25 ずつ稼ぎが伸びる（T3 までは ×T²）
- **超合金は「全武器を一斉に底上げする通貨」**。少なめのドロップ率を長期で集めて武器強化 Lv に投資
