# 06. パッチ（Patch）システム

## 概要

**パッチ (Patch)** は本作におけるパッシブ装備のロジック単位。THE TOWER の「カード」相当のポジションを担うが、本作では **特殊なパッシブスキル** と **無限合成 (Tier UP)** を中核に据える。

### 設計思想

- **単純なステ強化ではなく、条件付きトリガースキル中心**（即死 / 無効化 / 凍結 / 燃焼 / 復活 など）
- **ドロップは Tier ボスのみ・確率渋め**でエンドコンテンツ位置付け
- **強化通貨を介在させない**（合成のみで Tier UP）
- **Tier 上限なし**: 高 Tier に伸ばすほど数値部分が伸びる
- **レアリティ概念なし**: 効果の強弱は Tier 単一指標で表す

## ドロップ仕様

### ドロップ判定

| ドロップ源 | ドロップ確率 | 同時ドロップ数 |
|---|---|---|
| 通常敵 | 0%（ドロップなし） | — |
| エリート | 0%（ドロップなし） | — |
| ミニボス | 0%（ドロップなし） | — |
| Tier ボス | 20% × マシン「パッチドロップ率倍率」 | 1 |
| Tier クリア報酬 | なし（Tier ボス撃破ドロップに統合） | — |

> パッチは **Tier ボス撃破のみ** ドロップする。 さらに **1 ラン中最大 1 個**。
> Tier 進行と「パッチドロップ率倍率」 Lv (Max Lv 50 で ×5.0 倍 → 確定ドロップ) で実効ドロップ率を上げる。

### ドロップ Tier の分配（線形逆重み）

ドロップ判定で当選した後、ドロップするパッチの **Tier を別途抽選**。到達 Tier 以下のどの Tier かを「高 Tier ほどレア」な重みで選ぶ。

```
重み(T) = (到達Tier - T + 1)
合計重み = 1 + 2 + ... + 到達Tier = 到達Tier × (到達Tier+1) / 2
出現率(T) = 重み(T) / 合計重み
```

例: 到達 Tier 10 の場合、合計重み = 55

| Tier | 重み | 出現率 |
|---:|---:|---:|
| 1 | 10 | 18.2% |
| 2 | 9 | 16.4% |
| 3 | 8 | 14.5% |
| 4 | 7 | 12.7% |
| 5 | 6 | 10.9% |
| 6 | 5 | 9.1% |
| 7 | 4 | 7.3% |
| 8 | 3 | 5.5% |
| 9 | 2 | 3.6% |
| 10 | 1 | 1.8% |

### パッチの種類抽選

Tier が確定した後、**プール 10 種から均等抽選**で 1 種選ばれる。

## ネジ自動取得仕様

> マシンは盤面中央に固定で移動しないため、撃破時のネジは **自動取得**される。「マグネット」系パッチは不要。

## Tier と効果スケール

- パッチには **Tier (T)** が紐づく。初期取得時は任意（上記分配で抽選）
- **同 Tier 2 個 → 1 個 T+1 に合成**できる
- 合成は **手動 or 一括**。合成画面で +/- ステッパー で上限 Tier を選び、実行ボタンで一括合成。初期値は所持 Tier の最大（= 全部合成）
- **v1.3.4: 最新未クリア Tier (= `highestTier`) のパッチは合成で作れない**。 例 `highestTier=5` (Tier4 まで突破済み、 Tier5 が最新未クリア) のとき、 T4 ×2 → T5 への合成は不可。 T5 が欲しい場合は Tier5 出撃でドロップを狙う。 これにより「最新 Tier を突破する → 1 つ前の Tier のパッチを合成で量産できるようになる」 という形でクリアインセンティブが生まれる。

### スケール式（v1.5.0 全面改訂）

| 型 | 式 |
|---|---|
| **線形** | `効果値(T) = base × T`（上限なし） |
| **線形確率（オーバーフロー型）** | `p(T) = base + step × (T-1)`、上限なし。100% 超過分は `floor(p) + 端数確率で +1` で次の段階（追加発射 / 追加即死 / ドロップ倍率段階）に繰り越す。期待値は常に p で連続 |
| **線形確率（飽和型）** | 同式だが発動率は 100% で飽和。別の線形軸（凍結中与ダメ / DoT 係数）が無限成長を担う |
| **時間線形** | `秒数(T) = base + 0.2 × T` |
| **リジェネ基準** | `効果値(T) = 現在リジェネ × 係数 × T`（リジェネ投資と乗算で伸びる） |
| **確定型（バリア）** | `枚数(T) = 1 × T`（確率判定なし） |

> **v1.5.0 設計原則**: 漸近確率 (`T1 + (max-T1) × T/(T+20)`) と固定値スケールは**全廃**。
> 全パッチが「上限（MAX）のない成長軸」を最低 1 本持つ。詳細は [`15-balance-v1.5.0.md`](./15-balance-v1.5.0.md) §0〜§1 を参照。

## パッチプール (10 種)

> **トリガー列の表記**: パッチが発火するイベント種別を示す。実装は `src/game/patches.types.ts` の `PatchTrigger` および `src/game/patches/*.ts` 各ファイルを参照。
> - `onAttack`: マシンの攻撃が発生したタイミング（対象 enemyKind を伴う）
> - `onKill`: 敵を撃破したタイミング（v1.5.0: 現在リジェネ hpRegen を payload に含む）
> - `onDropRoll`: 撃破ドロップの抽選時
> - `onWaveClear`: ウェーブクリア時に 1 回発火（v1.5.0 で現プールでは未使用。将来拡張用に型は残す）
> - `interval`: 一定間隔ごと（現プールでは未使用）
> - **常時（パッシブ）**: トリガーではなく、装着中ずっと有効な倍率。専用 getter（`getShieldRegenMultiplier` / `getBoltGainMultiplier` / `getFrozenDamageBonusMul` / `getBarrierCapacity`）で参照する

## 効果スタックの計算

同名パッチは 1 個しか装着できないため、「同名スタック」は発生しない。
複数パッチが**同じステ・トリガに作用**する場合は、以下のルールで計算する。

```
1. 同じステを伸ばすパッチ同士は加算
2. その合計をマシン本体強化と乗算
3. ラン中ワークショップとも乗算
```

例: 「ボスキラー」が +25% (T5) で装備、ラン中 WS 攻撃力倍率 ×1.5 の場合:
- 通常ダメ → ボス類への与ダメ
- `dmg × 1.25 × 1.5 = dmg × 1.875`

確率系の場合は **OR で別判定**:
- 「インスタントキル 8%」と「ダブルショット 14%」を同時装備
- 即死判定とダブルショット判定は独立してロール

## 装着スロット

- 初期スロット数: **1**
- マシン強化「**パッチスロット数**」を上げることで最大 **6** まで増える
- スロット価格は [03-machine.md](./03-machine.md) を参照（Lv 0→1: 2k / Lv 4→5: 20M）

### 装着ルール

- 同名パッチは **1 スロットだけ装着可能**（同名重複装着は禁止）
- 合成用の重複所持は可（インベントリには同名・同 Tier を複数積める）
- **装着 / 取り外しは拠点でのみ可能**（ラン中の装備変更は不可）
- 同カテゴリスロット制限なし（Offensive ばかり 6 枚装備も可）

### 装着 UI フロー（パッチ庫「装着」タブ）

- **空きスロットをタップ** → 「装着候補ダイアログ」 を開く
  - 候補は **「インベントリに在庫があり、 かつ同名が他スロットに装着されていない」 パッチ** のみを列挙
  - 同名重複装着禁止ルールに従い、 既に装着済みの名前はリストから除外
  - 同名が複数 Tier 在庫にあるときは Tier ごとに別行で並べる（PatchCard 単位）
  - 候補をタップ → `equipPatch` を呼んでスロットに装着 → ダイアログを閉じる
  - 候補が 0 件のとき: 「装着可能なパッチが在庫にありません」 という空状態メッセージを表示（リストは出さない）
- **装着済みスロットをタップ** → 既存挙動どおり `unequipPatch` でその場で取り外し（ダイアログは開かない）
- ダイアログの構造: `Overlay` + `Card` + その中に `PatchCard` のリスト（自前で組む。汎用「アイテム選択ピッカー」 のような共通 Organism は導入しない）
- 背景タップ・閉じる × ボタンで装着せずキャンセル可能

## 合成 UI

### 手動合成

- インベントリで対象パッチを選択 → 「合成」ボタンで T → T+1 に 1 段階合成

### 一括合成

- 合成画面に「上限 Tier」設定（+/- ステッパー）
- 初期値は **所持 Tier の最大**（事実上「全合成」）
- 実行ボタンで指定 Tier 以下を可能な限り合成
- 取得時の自動合成はなし（戦闘中の即合成はしない）

## バランス上の留意点

- 同 Tier 2 個合成のため、T10 を 1 個作るには T1 を 2^9 = **512 個必要**（同名のみ）
- ドロップが渋いので、初期 Tier の高 Tier ドロップを除けば長期的な合成計画が必要
- Tier 進行と「パッチドロップ率倍率」両方を伸ばさないと合成材料が集まらない設計
- 「不死鳥」のような質的効果は今回プールに含めない（次の拡張パックで検討）
