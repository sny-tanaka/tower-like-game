# 12. サウンドエフェクト / BGM

本作で必要となるサウンドエフェクト (SE) と BGM の一覧と、実装優先度の仕分け。
具体的な音色・尺・音量カーブは claude design / サウンドデザイン担当に委譲し、本章では **どこで何の音が必要か** を定義する。

## 設計方針

- **無音にならない操作 / 演出を最優先**で揃える（タップ・撃破・被弾・購入）
- **高頻度音はレートリミット**（連続射撃 / 連続ヒット）または **プール再生** で潰さない
- **クリティカル / 即死 / ボーナス系は単体音でなくレイヤー音**として通常音に重ねる
- **拒否音・ボタン音・通貨獲得後の HUD 更新音は 1 つを共通化**して音数を抑える
- **武器ごとに通常射撃音を分ける**のは武器スワップ機能の核（無音や同音だと差別化が消える）
- **ドロップ系（パッチ / 通貨）は SE を鳴らさない**: HUD の数値更新だけで表現する。Tier ∞ で発生頻度が極端に増えるため、SE を鳴らすと耳障り & 処理負荷が上がる

## 優先度の凡例

| 記号 | 意味 |
|---|---|
| 🔴 | 実装必須（v1 リリース時に無いとゲーム体験が成立しない） |
| 🟡 | あると嬉しい（リリース後の早期追加候補） |
| 🟢 | 後回し（無くてもプレイに支障なし、要望ベース） |

## 共通化ガイドライン（音数を抑える指針）

| 共通化案 | カバーする場面 |
|---|---|
| 拒否音 1 つ | 通貨不足 / 武器 CD 中 / アクティブ CD 中 / 装着済みスロット / 装備上限超過 |
| 強化購入成功音 1 つ | マシン / 武器 / ラン中ワークショップ |
| ボタンタップ音 1 つ | 全画面の汎用タップ |
| 画面遷移音 1 つ | タイトル ↔ 出撃準備 ↔ 拠点画面群 |
| クリティカル / 即死 / ボーナス | レイヤー音として通常音に重ねる、単体では鳴らさない |

## 鳴らさないイベント（明示的に SE なし）

仕様上発生はするが、SE を割り当てないもの。`Fx` などビジュアル側で表現する。

- **パッチドロップ** / **ボーナスドロップ（patch: bonusDrop 発動）**
- **ネジ獲得 tick** / **ボルト獲得** / **超合金獲得**
- 通貨は HUD の数値変化と Fx（数値カウントアップ・アイコン明滅など）で表現
- パッチドロップは敵撃破 Fx に統合 or 画面内アイコン Fx で表現

## 実装メモ

- **音声ファイルの形式**: PWA 配信なので `.mp3` または `.ogg` 想定（ブラウザ対応度で選定）
- **音量バランス**: BGM / SE の音量はユーザー設定で独立調整（[08-data-model.md](./08-data-model.md) の `settings` 参照）
- **モバイル対応**: 初回タップまで `AudioContext` を起動できない iOS Safari 制約に注意（タイトル画面の「続きから / 新規開始」タップで起動）
- **同時再生数の上限**: 1 SE につき同時 4〜8 音までに制限、超過分は古い音を切る
