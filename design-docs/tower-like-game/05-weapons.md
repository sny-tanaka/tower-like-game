# 05. 武器 (Weapons) — 武器システム

本章では、マシンに装着する **武器 (Weapon)** とその強化体系を定める。

## 武器システム概要

- 武器は **マシンに 1 つだけ装着**。装着武器の通常攻撃挙動・アクティブスキルがマシンの攻撃挙動になる
- **4 種類の武器すべてが最初から開放**されており、ラン開始時に自由に選択
- 武器強化通貨は **超合金 (Alloy)**（永続）
- 武器強化 Lv は **全武器共通の 1 系統**（個別 Lv ではない）。1 つの Lv が上がると **4 武器すべての数値が同時に伸びる**。これにより「育てた武器以外を使わなくなる」事態を防ぐ
- 4 武器:
  1. **Laser** レーザー — 細い直線ビーム・遠射程・貫通
  2. **Cannon** 大砲 — 着弾点に範囲ダメ・低速
  3. **Thunder** サンダー — 同時 3 体への DoT、連鎖アクティブ
  4. **Cutter** カッター — マシン周囲を回転する高速近接

## 武器強化 Lv の構造

1 つの **武器強化 Lv** で、4 武器すべての以下 4 要素が同時に伸びる:

1. **武器ダメージ倍率** — 通常攻撃ダメージに乗算（マシン基礎攻撃力に掛ける係数）
2. **攻撃速度** — 通常攻撃の attacks/sec
3. **アクティブ威力** — アクティブスキルのダメージ・効果量
4. **固有ステ** — 武器ごとに異なる特殊ステ

### Lv あたりの伸び（全武器共通スケール）

| 要素 | 伸び |
|---|---|
| 武器ダメージ倍率 | 乗算 ×1.02 / Lv（初期 ×1.0） |
| 攻撃速度 | 線形 +0.03 × 武器底値 / Lv（武器ごとの底値に対する比率加算） |
| アクティブ威力 | 線形 +0.05 × アクティブ底威力 / Lv |
| 固有ステ | 武器ごとに固有設定。整数化対象は **切り捨て**、小数 OK 項目は連続値 |

代表 Lv での倍率早見:

| Lv | ダメ倍率 | AS 補正 | アクティブ威力補正 |
|---:|---:|---:|---:|
| 0 | ×1.00 | ×1.00 | ×1.00 |
| 10 | ×1.22 | ×1.30 | ×1.50 |
| 50 | ×2.69 | ×2.50 | ×3.50 |
| 100 | ×7.24 | ×4.00 | ×6.00 |

## 攻撃合成式

```
通常攻撃の素ダメ = マシン基礎攻撃力 × 武器ダメージ倍率 × 武器固有ダメ倍率(通常)
                  × 攻撃力倍率_RW × パッチ補正

アクティブ素ダメ = マシン基礎攻撃力 × 武器ダメージ倍率 × アクティブ威力倍率（武器固有）
                  × マシン アクティブ威力 × 攻撃力倍率_RW × パッチ補正

クリ時 = 素ダメ × クリ倍率（クリ率でロール）

最終被ダメ計算 (敵側) = max(0, 素ダメ − 敵防御力) × (1 − 敵 軽減率)
```

`_RW` はラン中ワークショップ由来（→ [04-run-workshop.md](./04-run-workshop.md)）。

実効 attacks/sec:
```
実効 AS = 武器底 AS × (1 + 0.03 × 武器Lv)
       × マシン攻撃速度倍率 (×1.02^マシン攻撃速度Lv)
       × 攻撃速度倍率_RW
       (上限 10 attacks/sec ハードキャップ)
```

## 4 武器の詳細

### 1. Laser レーザー

| 属性 | 内容 |
|---|---|
| 通常攻撃挙動 | **細い直線ビーム**を 1 発撃つ。索敵中の最寄りターゲットを通る一直線。 |
| ターゲッティング | 単体（最寄り） |
| 射程 | 索敵距離準拠 |
| 攻撃速度 底値 | **1.0 attacks/sec** |
| 固有ステ | **貫通数**（Lv 0 = 1、+0.1 / Lv、切り捨て表示） |
| アクティブ | **Mega Beam** — マシンから画面端まで届く幅 30 px の太いビーム、当たった敵を全てヒット |
| アクティブ威力 | 通常攻撃の **×10** |
| アクティブ CD | **20 秒** |

設計意図: 単体・ピーキーなクリ寄り武器。マシン本体「クリ率 / クリ倍率」と相性が良い。

### 2. Cannon 大砲

| 属性 | 内容 |
|---|---|
| 通常攻撃挙動 | 着弾点中心に **半径 30 px** の範囲ダメージ。低速。 |
| ターゲッティング | 着弾点中心の円形範囲 |
| 攻撃速度 底値 | **0.5 attacks/sec** |
| 固有ステ | **爆発半径**（Lv 0 = 30 px、+0.5 px / Lv、小数 OK） |
| アクティブ | **Volley** — 通常攻撃と同じターゲット起点に、72° ずつ放射状に 5 発の砲弾を撃つ。各々の爆発半径は通常攻撃の **×3**（Lv 0 で 90 px） |
| アクティブ威力 | **1 発あたり通常攻撃の ×20**（5 発合計 ×100） |
| アクティブ CD | **25 秒** |

設計意図: 群体処理。Tier 後半の人海戦術に強い。

### 3. Thunder サンダー

| 属性 | 内容 |
|---|---|
| 通常攻撃挙動 | 索敵範囲内の **最大 3 体** に同時 DoT を付与 |
| ターゲッティング | 同時 3 体 |
| 攻撃速度 底値 | **0.7 attacks/sec** |
| 固有ステ | **連鎖数**（Lv 0 = 7、+0.1 / Lv、切り捨て表示）— アクティブの連鎖跳ねる回数 |
| アクティブ | **Plasma Discharge** — 最初のターゲットから始めて、連鎖数まで隣接する敵に跳ねる |
| アクティブ威力 | 1 体目に **通常攻撃の ×15**、以降 **10% ずつ減衰**（1: 100% / 2: 90% / 3: 80% / ... / 7: 40%） |
| アクティブ CD | **30 秒** |

#### DoT のティック仕様

- 持続時間: **3 秒**
- ティック間隔: **1 秒**
- 1 ティックあたりダメージ: **通常攻撃ダメージの 50%**
- 累計ダメージ: 通常ダメ ×1.5（3 ティック × 50%）
- 同じ敵に複数回 DoT を付与した場合: **持続時間をリセット**（重ねがけは不可、最新付与で上書き）

設計意図: 持続火力。ラン中ワークショップ「攻撃力倍率」と相性が良い。

### 4. Cutter カッター

| 属性 | 内容 |
|---|---|
| 通常攻撃挙動 | マシン周囲を回転する **ノコギリ刃**。旋回半径内の敵に常時ヒット。 |
| ターゲッティング | 旋回半径内の複数体（同時ヒット数まで） |
| 攻撃速度 底値 | **2.0 attacks/sec**（旋回ヒット間隔として扱う） |
| 固有ステ | **旋回半径**（Lv 0 = 80 px、+0.5 px / Lv、小数 OK）+ **同時ヒット数**（Lv 0 = 1、+0.05 / Lv、切り捨て表示） |
| アクティブ | **Overdrive** — 8 秒間、攻撃速度倍率に ×3 が乗算される（マシン AS / ラン中 WS AS と乗算で重ねる） |
| アクティブ威力 | （AS バフのみ、ダメ倍率なし）— ただし Overdrive 中は ×3 で攻撃回数増加 |
| アクティブ CD | **35 秒** |

#### Overdrive の乗算スタック

```
Overdrive 中の AS = 通常実効 AS × 3
                 ≤ 10 attacks/sec（ハードキャップ）
```

他の AS 倍率と乗算で重ねがけ。10 attacks/sec キャップに容易に到達する。

設計意図: マシン本体・ラン中 WS の攻撃速度倍率の恩恵を二重に受ける武器。AS キャップを早期に踏みやすいぶん、その先はダメ倍率と固有ステで伸ばす。

## アクティブスキル — 発動モード

- ラン中の戦闘画面で **手動 / 自動** をいつでも切替（設定画面ではない、ラン中専用）
- **ラン開始時は手動で固定**
- 切替は **全武器共通 1 設定**

| モード | 挙動 |
|---|---|
| 手動 | 戦闘画面のアクティブボタンタップで発動。CD 中は disable 表示 |
| 自動 | CD 明けた瞬間に自動発動 |

### ターゲッティング（手動・自動共通）

ターゲットは全武器自動算出。プレイヤーは方向や位置を指定しない。

| 武器 | アクティブのターゲット起点 |
|---|---|
| Laser | 通常攻撃と同じターゲットの方向 |
| Cannon | 通常攻撃と同じターゲットを起点、72° ×5 放射 |
| Thunder | 通常攻撃と同じターゲットから連鎖開始 |
| Cutter | マシン中心（バフのみ） |

## 強化体系 (超合金消費)

### 共通ルール

- 強化通貨: **超合金 (Alloy)**
- 強化対象: 全武器共通の **武器強化 Lv** 1 個
- Lv 上限: なし
- コストカーブ:

```
cost_W(Lv) = ceil(200 × 1.12 ^ Lv)
```

### 代表 Lv のコスト

| Lv 進行 | コスト | Lv 0 → Lv 累計 |
|---:|---:|---:|
| 0 → 1 | 200 | 200 |
| 9 → 10 | 555 | 3,479 |
| 19 → 20 | 1,723 | 13,288 |
| 49 → 50 | 50,358 | 462,302 |
| 99 → 100 | 13,624,000 | 約 113M |

## マシン本体強化・ラン中ワークショップとの関係

- 武器の超合金 Lv は **武器のベース値**（4 要素）を決める
- マシン本体強化（基礎攻撃力 / 攻撃速度 / クリ率 / クリ倍率 / アクティブ威力 / CD 減少）と **乗算で重ねがけ**
- ラン中ワークショップ（攻撃力倍率 / 攻撃速度倍率）と **乗算で重ねがけ**
- ラン中ワークショップ「攻撃力倍率」は通常攻撃にもアクティブスキルにも適用

## 表示・計算丸めルール

- 効果値（ダメージ / AS / 半径 / 倍率）の丸めは [03-machine.md](./03-machine.md) の方針に従う
- 武器固有ステの整数項目（貫通数 / 連鎖数 / 同時ヒット数）は **切り捨て**（プレイヤー有利になりすぎない側）
- 半径系（爆発半径 / 旋回半径）は内部値そのまま小数で扱い、表示は小数点 1 桁
