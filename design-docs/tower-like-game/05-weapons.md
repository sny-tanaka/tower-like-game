# 05. 武器 (Weapons) — 武器システム

本章では、マシンに装着する **武器 (Weapon)** とその強化体系を定める。

## 武器システム概要

- 武器は **マシンに 1 つだけ装着** する。装着武器の通常攻撃挙動・アクティブスキルがそのままマシンの攻撃挙動になる。
- **4 種類の武器すべてが最初から開放されており、ラン開始時に自由に選択** できる (アンロック制ではない)。
- 武器の強化通貨は **超合金 (Alloy)** (永続通貨)。武器ごとに独立した強化 Lv を持つ。
- 武器は **1 本化 Lv** という単一の Lv のみで強化する。1 Lv 上げると、その武器の 4 つの要素が同時に伸びる。
- 4 武器:
  1. **Bow 弓** — 単体直線弾・遠射程・高クリ寄り
  2. **Cannon 大砲** — 着弾点に範囲ダメージ・低速
  3. **Tome 魔導書** — 同時 3 体への DoT
  4. **Blades 双剣** — 周囲旋回斬り・近距離

## 1 本化 Lv の構造

1 本化 Lv は **単一の数値で 4 要素を同時に上げる** 設計。プレイヤーは「どの武器に超合金を注ぐか」だけを判断し、内部配分は気にしない。

1 Lv で同時に伸びる 4 要素:

1. **基礎ダメージ** — 通常攻撃のダメージ
2. **攻撃速度** — 通常攻撃の発射頻度
3. **アクティブ威力** — アクティブスキルのダメージ / 効果量
4. **固有ステータス** — 武器ごとに異なる特殊ステ (貫通数 / 爆発半径 / 連鎖数 / 旋回半径+同時ヒット数)

- 4 要素の伸び率は武器ごとに調整する (例: Bow は基礎ダメと固有ステを厚め、Cannon はアクティブ威力厚め、など)。

## 4 武器の詳細

### 1. Bow 弓

| 属性 | 内容 |
|---|---|
| 通常攻撃挙動 | 単体直線弾。索敵範囲内の最寄り (または最優先) の敵に向けて一直線に矢を発射。 |
| ターゲッティング | 単体 |
| 射程 | 遠 (索敵距離に強く依存、上限緩め) |
| 想定特徴 | 高クリ寄り。クリ率 / クリ倍率の恩恵を最大化しやすい武器。 |
| 固有ステ | **貫通数** — 1 本の矢が貫通する敵の最大数 |
| アクティブスキル | **貫通矢** — 直線範囲攻撃。指定方向 (または最遠方向) に超強力な貫通矢を 1 発撃ち、貫通数を一時的に無制限化。 |
| アクティブ CD | TBD: 初期 CD 秒数 |
| 想定威力倍率 | 通常攻撃の n 倍 (TBD: 具体倍率) |

- 設計意図: マシン本体強化のクリ率 / クリ倍率と相性が良い武器。ラン中ワークショップの攻撃速度倍率で実 DPS が伸びる。

| 属性 | 内容 |

| 射程 | 中 |

### 4. Blades 双剣

| 属性 | 内容 |
|---|---|
| 通常攻撃挙動 | マシンの周囲を旋回しながら近距離の敵を斬り続ける。 |
| ターゲッティング | 旋回半径内の複数体 (同時ヒット数まで) |
| 射程 | 近 (旋回半径) |
| 想定特徴 | 近距離限定の代わりに常時ヒット。攻撃速度の概念は旋回速度 / ヒット間隔として扱う。 |
| 固有ステ | **旋回半径** + **同時ヒット数** (1 本化 Lv で両方が伸びる) |
| アクティブスキル | **乱舞** — 8 秒間、双剣の旋回速度 / ヒット間隔を ×3 化 (= 攻撃速度 ×3 相当)。 |
| アクティブ CD | TBD: 初期 CD 秒数 |
| 想定威力倍率 | 通常攻撃の n 倍 (TBD: 通常 DPS × 3 × 8 秒、CD 込みの実効値で再計算) |

- 「乱舞」は攻撃力ではなく攻撃速度をブーストする点が他武器と異なる。
- 設計意図: マシン本体の攻撃速度 / ラン中ワークショップ攻撃速度倍率の恩恵を二重に受けやすい武器。

## アクティブスキル — 発動モード

アクティブスキルは、設定で **手動 / 自動** を切り替え可能。

| モード | 挙動 |
|---|---|
| 手動 | プレイヤーが画面上のアクティブボタンをタップで発動。CD 中は disable 表示。 |
| 自動 | CD が明けた瞬間に自動発動。発動条件のしきい値 (例: 敵が n 体以上、ボス出現時、など) は TBD。 |

- 設定はゲーム設定 (永続) で保持する。ラン中も切替可能。
- 手動 / 自動の切替は **武器ごとに独立** とするか **全武器共通の 1 設定** かは TBD。
- アクティブ発動位置の指定が必要な武器 (Cannon 砲撃の指定範囲、Bow 貫通矢の指定方向など) について:
  - 自動モード時の自動指定ロジックは TBD (例: 索敵範囲の重心 / 最敵密集点 / マシン向き)。
  - 手動モード時の指定 UI も TBD (タップ位置に発動など)。

## 強化体系 (超合金消費)

### 共通ルール

- 強化通貨: **超合金 (Alloy)** (永続通貨)
- 強化対象: 1 本化 Lv (各武器ごとに独立)
- Lv 上限: なし
- コストカーブ: 指数増加

```
cost_W(Lv) = base_W × growth_W ^ Lv
```

- `base_W`: 武器ごとの初期コスト
- `growth_W`: 武器ごとの成長係数 (> 1.0)
- 4 武器ともに同等の総コスト水準を目指す (どれを伸ばしても損しない設計)。

## マシン本体強化・ラン中ワークショップとの関係

- 武器の超合金 Lv は **武器のベース値** を決める。
- それに対し:
  - マシン本体強化 (基礎攻撃力 / 攻撃速度 / クリ率 / クリ倍率 / アクティブ威力 / アクティブ CD 減少) が **加算 or 乗算** で乗る (→ [03-machine.md](./03-machine.md))。
  - ラン中ワークショップ (攻撃力倍率 / 攻撃速度倍率) が **乗算** で乗る (→ [04-run-workshop.md](./04-run-workshop.md))。
- アクティブ威力には:
  - マシン本体強化 #10「アクティブ威力」が **乗算** で適用。
  - ラン中ワークショップ「攻撃力倍率」が乗るかは TBD ([04-run-workshop.md](./04-run-workshop.md) と整合)。
