# 05. 武器 (Weapons) — 武器システム

本章では、マシンに装着する **武器 (Weapon)** とその強化体系を定める。

> **v1.1 ロール再設計**: 4 武器がそれぞれ「特定の場面で唯一の最適解」となるよう、底値・射程・固有 Lv 強化軸・アクティブを再設計した。詳細経緯と設計判断は [14-weapons-rebalance-v1.1.md](./14-weapons-rebalance-v1.1.md) 参照。

## 武器システム概要

- 武器は **マシンに 1 つだけ装着**（同時に使えるのは 1 種）。装着武器の通常攻撃挙動・アクティブスキルがマシンの攻撃挙動になる
- **4 種類の武器すべてが最初から開放**されており、ラン開始時に **初期装備武器** を選ぶ
- **ラン中も武器切替可能**（戦略性の確保。詳細は後述）
- 武器強化通貨は **超合金 (Alloy)**（永続）
- 武器強化 Lv は **全武器共通の 1 系統**（個別 Lv ではない）。1 つの Lv が上がると **4 武器すべての数値が同時に伸びる**。これにより「育てた武器以外を使わなくなる」事態を防ぐ
- **射程は武器別に固定**（v1.1）。`WEAPON_RANGE_PCT` マップ:
  - Cutter 14%（近接旋回） / Laser 35%（単体狙撃） / Thunder 35%（中距離散開） / Cannon 45%（遠距離砲）
- 4 武器のロール (v1.1):
  1. **Laser** レーザー — 単体高 DPS。Lv で critMultiplier ボーナス +0.01/Lv
  2. **Cannon** 大砲 — 遠距離 splash 爆発。**マシン背面側はカット**（前方半円のみ）
  3. **Thunder** サンダー — 中距離・同時 3 体独立落雷。**攻撃時 HP 回復** 0.1%/Lv
  4. **Cutter** カッター — 近接 2 枚刃旋回（180° 配置で前後 2 体同時）。Overdrive で AS×3 + dmgMul×3

## ラン中の武器切替

ラン中、プレイヤーは状況に応じて 4 武器を切替えて使い分けられる。「敵が近距離に密集 → Cutter」「遠距離単体 → Laser」「群体 → Cannon」「持続火力 → Thunder」など、戦略的選択が可能。

### 切替仕様

| 項目 | 内容 |
|---|---|
| 切替操作 | バトル画面下 HUD の **武器 4 アイコン** から目的の武器をタップ |
| 切替 CD | **3 秒**（最後の切替から 3 秒間は他の武器に切替えられない） |
| 切替コスト | なし（ネジ消費なし） |
| 切替後の即発射 | 通常攻撃の次のサイクルから新武器の挙動になる（即時切替、待機なし） |
| 切替の制限 | アクティブ発動中（Cutter Overdrive など）でも可能 |
| ポーズ中の切替 | 可能（CD は一時停止時間も進行） |

### 切替時の状態保持

| 状態 | 切替後の挙動 |
|---|---|
| **付与済み燃焼 DoT**（燃焼ヒットパッチなど） | 付与済みの敵に **持続したまま**。切替で消えない |
| **凍結状態**（凍結ヒット） | 付与済みの敵に持続 |
| **Cutter Overdrive バフ** | Cutter を外しても **マシン側にバフが残り続ける**（AS ×3 はマシン基礎値に乗る）。Overdrive 終了でクリア |
| **アクティブ CD** | **武器ごとに独立**。例: Laser のアクティブを撃った後 Cannon に切替えると Cannon は CD なしで撃てる。Laser に戻すと残り CD から再開 |

### ラン開始時の挙動

- ラン開始時の **初期装備武器** は出撃準備画面で選ぶ（4 武器から 1 つ）
- ラン中に切替してもラン終了で破棄、次ラン開始は出撃準備で選んだ初期装備で開始
- **アクティブ CD は全武器ともゲージ 0（= CD 満タン）でラン開始**。出撃直後は発動不可で、`DEFAULT_ACTIVE_MAX_SEC`（= 60 秒）経過してゲージが満タンになって初めて発動可能になる（v0.2.0 で旧仕様「ラン開始時に CD 0 = 即発動可能」から変更）

## 武器強化 Lv の構造

1 つの **武器強化 Lv** で、4 武器すべての以下 4 要素が同時に伸びる:

1. **武器ダメージ倍率** — 通常攻撃ダメージに乗算（マシン基礎攻撃力に掛ける係数）
2. **攻撃速度** — 通常攻撃の attacks/sec
3. **アクティブ威力** — アクティブスキルのダメージ・効果量
4. **固有ステ** — 武器ごとに異なる特殊ステ

### Lv あたりの伸び（v1.1.1 改訂）

> **v1.1.1 で武器Lv はダメージ / 攻撃速度 / アクティブ威力倍率を一切伸ばさなくなった**。これらの伸びは
> マシン本体強化（基礎攻撃力 / 攻撃速度倍率）に集約。武器Lv は各武器の固有 Lv 強化軸 **1 つ**だけに作用する。

| 要素 | 伸び |
|---|---|
| 武器ダメージ倍率 | **武器底値で固定（武器Lv では伸びない）** |
| 攻撃速度 | **武器底値で固定（武器Lv では伸びない）** |
| アクティブ威力倍率 | **固定**（Mega Beam ×50, Volley ×10, Plasma ×10、Overdrive ×9 すべて固定） |
| 固有 Lv 強化軸 | 武器ごとに **1 つだけ**。下表参照 |

### 武器固有 Lv 強化軸（v1.1、各武器 1 軸）

「同時ヒット数」は **Lv で増えない**（ロール崩壊防止）。代わりにロールを深化させる軸を 1 つだけ持つ:

| 武器 | 強化軸 | 式 | Lv 60 値 |
|---|---|---|---|
| Laser | critMultiplier ボーナス | `+0.01 × Lv` | +0.6（base 1.5 → 2.1） |
| Cutter | Overdrive 持続秒 | `8 + 0.1 × Lv` | 14s |
| Thunder | 攻撃時 HP 回復率 | `0.001 × Lv`（= 0.1%/Lv） | 6% |
| Cannon | splash 半径(px) | `30 + 0.5 × Lv` | 60px |

代表 Lv での倍率早見:

| Lv | ダメ倍率 | AS 補正 | アクティブ威力補正 |
|---:|---:|---:|---:|
| 0 | ×1.00 | ×1.00 | ×1.00 |
| 10 | ×1.22 | ×1.30 | ×1.50 |
| 50 | ×2.69 | ×2.50 | ×3.50 |
| 100 | ×7.24 | ×4.00 | ×6.00 |

## 攻撃合成式

```
通常攻撃の素ダメ = マシン基礎攻撃力 × 武器ダメージ倍率 × 武器固有ダメ倍率(通常)
                  × 攻撃力倍率_RW × パッチ補正

アクティブ素ダメ = マシン基礎攻撃力 × 武器ダメージ倍率 × アクティブ威力倍率（武器固有）
                  × マシン アクティブ威力 × 攻撃力倍率_RW × パッチ補正

クリ時 = 素ダメ × Critical倍率（Critical率でロール）

最終被ダメ計算 (敵側) = max(0, 素ダメ − 敵防御力) × (1 − 敵 軽減率)
```

`_RW` はラン中ワークショップ由来（→ [04-run-workshop.md](./04-run-workshop.md)）。

実効 attacks/sec:
```
実効 AS = 武器底 AS × (1 + 0.03 × 武器Lv)
       × マシン攻撃速度倍率 (×1.02^マシン攻撃速度Lv)
       × 攻撃速度倍率_RW
       (上限 10 attacks/sec ハードキャップ)
```

## 4 武器の詳細

### 1. Laser レーザー（v1.1）

| 属性 | 内容 |
|---|---|
| 通常攻撃挙動 | **細い直線ビーム**を 1 発撃つ。索敵中の最寄りターゲットを通る一直線。 |
| ターゲッティング | 単体（最寄り） |
| 射程 | **35%**（中距離） |
| 攻撃速度 底値 | **2.5 attacks/sec** |
| 武器ダメ倍率 底値 | **0.8**（DPS 単体 2.0 = 全武器最強） |
| 固有 Lv 強化軸 | **critMultiplier ボーナス** `+0.01 × Lv`（machine.critMultiplier に加算してクリ時ダメに反映） |
| 固定値 | 貫通数 **1（Lv で増えない）** |
| アクティブ | **Mega Beam** — 幅 **12%** の太いビーム、貫通無限。直線上の全敵に被弾 |
| アクティブ威力 | 通常攻撃の **×50**（Lv 0 で 1 発単体 40 ダメ） |
| アクティブ CD | 初期値はアクティブ共通 60 秒（[後述](#アクティブスキル--発動モード)） |

設計意図: 単体ロール特化。Lv が上がるほどクリ時の倍率が伸び、単体相手の DPS ピークが他武器を引き離す。

### 2. Cannon 大砲（v1.1）

| 属性 | 内容 |
|---|---|
| 通常攻撃挙動 | 砲弾が直線飛翔して着弾し、 着弾点中心 **半径 30 + 0.5×Lv (px)** に範囲ダメージ。 **マシン背面側はカット** (前方半円のみ)。 着弾点は「砲弾 × 敵直線運動の交点」 で予測 (v1.1.2)。 ダメージは **着弾時の敵分布** で計算され、 **距離減衰** (中心 100% → 半径ギリギリ 30%) で減る |
| ターゲッティング | 予測着弾点中心の **半円範囲**（マシン → 着弾点方向と同向きの敵のみ）、 距離で減衰 |
| 射程 | **45%**（遠距離、最遠） |
| 攻撃速度 底値 | **0.5 attacks/sec** |
| 武器ダメ倍率 底値 | **3.0**（DPS 単体 1.5、AS が遅い代わりに 1 撃が重い） |
| 固有 Lv 強化軸 | **splash 半径**（`30 + 0.5 × Lv` px） |
| アクティブ | **Volley** — 通常攻撃と同じターゲット起点に、72° ずつ放射状に 5 発の砲弾を撃つ。各々の splash 半径は通常攻撃の **×3**。各砲弾の splash にも半円カットを適用 |
| アクティブ威力 | **1 発あたり通常攻撃の ×10**（5 発合計 ×50） |
| アクティブ CD | 初期値はアクティブ共通 60 秒（[後述](#アクティブスキル--発動モード)） |

#### Cannon splash 半円カット仕様

マシン位置 `(50, 50)`、着弾点 `(bx, by)`、敵 `(ex, ey)` に対し、splash 内ダメ判定は次の **両方** を満たす場合のみ:

1. `dist((bx, by), (ex, ey)) ≤ splashRadius`
2. `(ex - 50) × (bx - 50) + (ey - 50) × (by - 50) > 0`（マシン→着弾点ベクトルと、マシン→敵ベクトルの内積が正 = マシンより着弾側の敵）

これにより「マシンを越えて反対側まで爆風が広がる」挙動を撤去。Cutter（周囲 360°）との密着時差別化を成立させる仕様。

#### Cannon 着弾予測 + 距離減衰 (v1.1.2)

砲弾は速度 `CANNON_SHELL_SPEED_PCT_PER_SEC = 50 (% / 秒)` で直線飛翔する。 敵はマシン中心に直線移動するので、 発射時に「砲弾と敵の交点」 を予測して着弾点を決める:

```
factor    = shellSpeed / (shellSpeed + enemy.speed)
blastX    = machineX + (targetX - machineX) × factor
blastY    = machineY + (targetY - machineY) × factor
flightSec = |D| / (shellSpeed + enemy.speed)   ※|D| = 敵までの距離
```

着弾時 (= flightSec 後) に **その瞬間の敵分布** で splash 判定を行う:
- 距離 0 (中心): 100% ダメ
- 距離 splashRadius (ギリギリ): **30%** ダメ (`SPLASH_EDGE_FACTOR = 0.3`)
- 中間: 線形補間 `falloff = 1 - 0.7 × (d / splashRadius)`

砲弾飛翔中に敵が splash 内へ入れば命中するし、 抜ければ命中しない。 同様に飛翔中に死んだ敵には当たらない。

設計意図: 遠距離からの範囲爆発。前方密集相手の splash バーストが圧倒的。**密着戦では半円カットで Cutter に負ける**。距離減衰で「中心ピン打ち」のキレ味と「端っこ被弾」のヌルさが出る。

### 3. Thunder サンダー（v1.1）

| 属性 | 内容 |
|---|---|
| 通常攻撃挙動 | 索敵範囲内の **最大 3 体に独立した落雷** を同時に落として即時ダメージを与える |
| ターゲッティング | 同時 3 体（chainCount 固定 3） |
| 射程 | **35%**（中距離、散開敵向け） |
| 攻撃速度 底値 | **2.0 attacks/sec** |
| 武器ダメ倍率 底値 | **0.45**（DPS 単体 0.9 / 3 体時 2.7） |
| 固有 Lv 強化軸 | **攻撃時 HP 回復率** `hpLifestealPct = 0.001 × Lv`（通常 / Plasma 双方で与ダメ合計 × Pct を machineHp に回復、machineMaxHp 上限） |
| アクティブ | **Plasma Discharge** — **全フィールド・全敵に均一ダメージ**（射程無限・連鎖廃止） |
| アクティブ威力 | 全敵に均一 **通常攻撃の ×10**（Lv 0 で 1 体 4.5 ダメ） |
| アクティブ CD | 初期値はアクティブ共通 60 秒（[後述](#アクティブスキル--発動モード)） |

設計意図: 中距離の散開敵処理 + サポート（雷の電力供給がマシン本体を回復するイメージ）。Plasma は雑魚大量殲滅・ボス削り両用。

### 4. Cutter カッター（v1.1）

| 属性 | 内容 |
|---|---|
| 通常攻撃挙動 | マシン周囲を回転する **2 枚刃**。各刃が現在角度から `360° / 2 = 180°` の弧を sweep し、その範囲内の **全敵** にヒット |
| ターゲッティング | sweep 弧範囲内の **全敵** （v1.1.2 で上限撤廃）。1 rotation あたり各敵に **blades 回** （= 2 回）ヒット |
| 射程 | **14%**（近接、最短） |
| 攻撃速度 底値 | **1.0 attacks/sec**（旋回ヒット間隔として扱う、描画見やすさ優先で v0.2.0 の 2.5 から減速） |
| 武器ダメ倍率 底値 | **1.2**（DPS 単体 1.2 / 2 体時 2.4） |
| 固有 Lv 強化軸 | **Overdrive 持続秒** `8 + 0.1 × Lv`（Lv 60 で 14s） |
| 固定値 | blades **2（Lv で増えない）**、旋回半径 80 px 固定 |
| アクティブ | **Overdrive** — 持続中、**AS ×3 + dmgMul ×3**（DPS 倍率 9）。マシン AS / ラン中 WS AS と乗算で重ねる |
| アクティブ CD | 初期値はアクティブ共通 60 秒（[後述](#アクティブスキル--発動モード)） |

#### Cutter 当たり判定の詳細

- 2 枚刃が 180° で配置されるので、たとえば敵が x=60 と x=40 にいるとき両方に同時ヒット可能
- 各刃は中心角 `θ_sweep = 180°` の弧を、前フレームから今フレームの角度差分だけ進む
- 当たり判定はこの弧（角度範囲）と旋回半径円のリング領域の交差
- 「視覚的に刃が通過した範囲 = 判定範囲」、 範囲内の **全敵** にダメージ (v1.1.2: 旧仕様の 「最大 blades 体」 上限を撤廃)
- 1 fire = 1 / blades 回転分の判定。1 rotation (= blades 回 fire) で各敵は blades 回 (= 2 回) のヒットを受ける

#### Overdrive の乗算スタック

```
Overdrive 中の AS    = 通常実効 AS × 3   ≤ 10 attacks/sec（ハードキャップ）
Overdrive 中の dmg   = 通常 dmg × 3
Overdrive 中の DPS   = 通常 DPS × 9
Overdrive 持続秒     = 8 + 0.1 × weaponLv
```

設計意図: 近接で 2 体以上に密着するときに最強。Cutter 範囲内 2 体時 DPS = 2.4 が Laser 単体 2.0 を超え、Overdrive 中は爆発的なバースト。**単体相手では Laser に大きく劣り、リスクの代償**。

## アクティブスキル — 発動モード

- ラン中の戦闘画面で **手動 / 自動** をいつでも切替（設定画面ではない、ラン中専用）
- **ラン開始時は手動で固定**
- 切替は **全武器共通 1 設定**
- **アクティブ CD 初期値は全武器共通 60 秒**（v0.2.0 で従来の 20 / 25 / 30 / 35 秒個別設定から統一）。
  マシン本体「アクティブ CD 減少」（→ [03-machine.md](./03-machine.md)）が乗算で短縮する
- **ラン開始時のゲージ初期値は 0（= CD 満タン状態）**。出撃直後の発動はできず、60 秒の CD を消化してゲージが満タンになって初めて 1 回目を撃てる。ゲージの表示方向は **「発動 = 0 → 時計回りで満タンへ溜まる」** に統一

| モード | 挙動 |
|---|---|
| 手動 | 戦闘画面のアクティブボタンタップで発動。CD 中は disable 表示 |
| 自動 | CD 明けた瞬間に自動発動 |

### ターゲッティング（手動・自動共通）

ターゲットは全武器自動算出。プレイヤーは方向や位置を指定しない。

| 武器 | アクティブのターゲット起点 |
|---|---|
| Laser | 通常攻撃と同じターゲットの方向（v1.1 でビーム幅 12%、貫通無限） |
| Cannon | 通常攻撃と同じターゲットを起点、72° ×5 放射（v1.1 で各 splash に半円カット適用） |
| Thunder | **全フィールド・全敵に均一ダメ**（v1.1 で連鎖廃止、射程無限の全体攻撃に変更） |
| Cutter | マシン中心（v1.1 で AS×3 + dmgMul×3 のバフ、持続 `8 + 0.1×Lv` 秒） |

## 強化体系 (超合金消費)

### 共通ルール

- 強化通貨: **超合金 (Alloy)**
- 強化対象: 全武器共通の **武器強化 Lv** 1 個
- Lv 上限: なし
- コストカーブ:

```
cost_W(Lv) = ceil(200 × 1.12 ^ Lv)
```

### 代表 Lv のコスト

| Lv 進行 | コスト | Lv 0 → Lv 累計 |
|---:|---:|---:|
| 0 → 1 | 200 | 200 |
| 9 → 10 | 555 | 3,479 |
| 19 → 20 | 1,723 | 13,288 |
| 49 → 50 | 50,358 | 462,302 |
| 99 → 100 | 13,624,000 | 約 113M |

## マシン本体強化・ラン中ワークショップとの関係

- 武器の超合金 Lv は **武器のベース値**（4 要素）を決める
- マシン本体強化（基礎攻撃力 / 攻撃速度 / Critical率 / Critical倍率 / アクティブ威力 / CD 減少）と **乗算で重ねがけ**
- ラン中ワークショップ（攻撃力倍率 / 攻撃速度倍率）と **乗算で重ねがけ**
- ラン中ワークショップ「攻撃力倍率」は通常攻撃にもアクティブスキルにも適用

## 表示・計算丸めルール

- 効果値（ダメージ / AS / 半径 / 倍率）の丸めは [03-machine.md](./03-machine.md) の方針に従う
- 武器の整数項目（貫通数 / 連鎖数 / blades）は **切り捨て**（プレイヤー有利になりすぎない側）。v1.1 ではいずれも Lv で増えない固定値
- 半径系（splash 半径 / 旋回半径）は内部値そのまま小数で扱い、表示は小数点 1 桁
- HP 回復率（Thunder hpLifestealPct）は内部値そのまま小数、表示は %（小数点 1 桁）
