# 00 — 概要 (Overview)

本ドキュメントは、個人開発タイトル **Tower Like Game** の全体像をまとめたものです。
本作は THE TOWER (Idol Tower Defence) をオマージュした **タワーディフェンス系の放置寄りラン RPG** で、
PWA としてブラウザ上で動作することを前提に設計されています。

---

## 1. ゲームジャンル

- **ジャンル**: シングルプレイのタワーディフェンス × ラン RPG（ローグライク的なメタ進行を伴う）
- **視点**: 真俯瞰、画面中央に自機を据えた 360° 全方位防衛
- **テンポ**: ウェーブ制（1 ウェーブあたり 26 秒）、放置寄りで片手プレイが可能
- **プレイ時間の単位**: 1 ラン = 数分〜数十分（到達 Tier に依存）

## 2. プラットフォーム

| 項目 | 内容 |
|---|---|
| 配信形態 | PWA（ホーム画面追加可能、オフライン起動を想定） |
| 動作環境 | モダンブラウザ（モバイル / デスクトップ両対応） |
| メイン入力 | スマホ片手操作（タップ中心、長押し最小限） |
| サーバ | 持たない。すべてクライアント完結 |
| セーブ先 | **IndexedDB**（端末ローカル） |
| 課金 | なし |
| オンライン要素 | なし（ランキング・対戦・ギルド・トーナメント等は一切なし） |

## 3. コアコンセプト

- **「マシン 1 体 vs 360° から押し寄せる敵」** という構図に絞り、本家の複雑要素（BOT・ガーディアン・モジュール・課金通貨・トーナメント等）を削ぎ落とす。
- **ラン進行とメタ進行の二段構造** で、毎ランの結果を永続強化に還元する。
- **動的 Tier** により、進行に上限のない長期遊技を可能にしつつ、エンドレスモードは設けない（Tier そのものが無限スケール）。
- **片手操作・短セッション・PWA** をプレイ体験の中心に据える。

## 4. コアループ

```
[ラン開始] → [戦闘 (Tier 内 30 ウェーブ)] → [リザルト] → [永続化 (ボルト/超合金/パッチ)]
   ↑                                                                    │
   └─────────── [マシン強化 / 武器強化 / パッチ整理] ←────────────────┘
```

1. **ラン開始**: ホーム → プレイ準備で挑戦 Tier・武器・装着パッチを確認して出撃。
2. **戦闘**: 1 Tier = 30 ウェーブを連続消化。途中エリート/ミニボス/Tier ボスを挟む。
3. **リザルト**: 撃破到達 Tier、獲得通貨、ドロップしたパッチを表示。
4. **永続化**: ボルト・超合金・パッチがメタ進行側に蓄積される（ネジは消滅）。
5. **再強化**: マシン本体 16 項目 / 武器強化 Lv（共通 1 個）/ パッチ装着 を更新して次ランへ。

## 5. ラン構造

1 ランの流れを画面遷移単位で示す。

| ステップ | 画面 | 主な決定事項 |
|---|---|---|
| 1 | プレイ準備 | 挑戦 Tier、使用武器（4 種から 1 種）、装着パッチ（スロット数まで）の最終確認 |
| 2 | 戦闘 | Tier 内 30 ウェーブを順次消化（5/10/20/30 ウェーブ目に強敵） |
| 3 | リザルト | 到達 Tier、被ダメージ、獲得ボルト/超合金、ドロップパッチを表示 |
| 4 | ホーム復帰 | 必要に応じてマシン強化 / 武器庫 / パッチ庫 へ |

### 1 Tier の内部構造

- **30 ウェーブ / Tier**、ウェーブ間隔 **26 秒**
- **5 ウェーブごとにエリート**（強化版通常敵）出現
- **10 / 20 ウェーブ目にミニボス**（パッチ確率ドロップ）
- **30 ウェーブ目に Tier ボス**（パッチ確定ドロップ + Tier クリア報酬）
- 撃破できなかった時点でランは終了、リザルトへ
- **エンドレスモードは存在しない**（Tier 数字そのものが無限に伸びる）

### 速度倍率

- ゲーム内速度: **1x / 2x / 3x / 5x** に加えて一時停止
- 速度切替は HUD のボタンから即時反映

## 6. システム階層図

本作の強化系は **3 層構造** で整理する。

```
┌────────────────────────────────────────────────────────────┐
│ メタ進行（ラン跨ぎ・永続）                                  │
│                                                            │
│   [マシン本体強化 16 項目]    通貨: ボルト (Bolt)          │
│   [武器強化 Lv (全武器共通 1個)] 通貨: 超合金 (Alloy)      │
│   [パッチ庫 (装着/保管/合成)] 通貨: なし（合成のみ）        │
└──────────────────────────┬─────────────────────────────────┘
                           │ (ラン開始で持ち込み)
                           ▼
┌────────────────────────────────────────────────────────────┐
│ ラン内進行（ラン内のみ・終了で消滅）                        │
│                                                            │
│   [ラン中ワークショップ 4 項目]  通貨: ネジ (Screw)         │
│   ・攻撃力倍率 / 攻撃速度倍率 / HP 倍率 / ネジ獲得倍率       │
└────────────────────────────────────────────────────────────┘
```

- **マシン**: 永続のベース性能。攻撃・防御・経済・スロットの軸を 16 項目で持つ。
- **武器**: 4 種から 1 種を選択（Laser / Cannon / Thunder / Cutter）。**強化 Lv は全武器共通の 1 個**で、上げると 4 武器すべての数値が同時に伸びる。装備武器交換時のロスをなくす設計。
- **パッチ**: パッシブ装備。同 Tier 2 個合成で 1 Tier UP、Tier 上限なし。レアリティ概念は持たない。

## 7. 削除した本家要素

本作は意図的にスコープを絞っているため、以下は **実装しない**:

- BOT（プレイヤー支援ユニット）
- ガーディアン
- モジュール 4 部位
- 究極の武器 9 種
- トーナメント / リーグ / レーティング
- ギルド / フレンド / 協力プレイ
- ストア / 課金通貨 / 広告報酬
- エンドレスモード（Tier が無限スケールするため不要）

## 8. 用語集

ローマ字併記で統一する。UI 文言・コード上の識別子・本仕様書のすべてで本用語を厳守する。

| 用語 | 英表記 | 説明 |
|---|---|---|
| マシン | Machine | プレイヤー自機。本家「タワー」に相当 |
| ネジ | Screw | ラン中通貨。ラン中ワークショップでのみ消費、**ラン終了で消滅** |
| ボルト | Bolt | 永続通貨。マシン本体 16 項目の強化に使用 |
| 超合金 | Alloy | 永続通貨。武器強化 Lv（全武器共通 1 個）の強化に使用 |
| パッチ | Patch | パッシブ装備。スロットに装着して常時効果を得る |
| Tier | Tier | 進行段位。Tier 1 → ∞、計算式で敵ステを動的生成 |
| ウェーブ | Wave | 1 Tier 内の 30 区切り。ウェーブ間隔 26 秒 |
| エリート | Elite | 5 ウェーブごとに出現する強化通常敵 |
| ミニボス | Mini-boss | 10 / 20 ウェーブ目に出現するボス級個体 |
| Tier ボス | Tier Boss | 30 ウェーブ目に出現する Tier 最終ボス |
| 武器強化 Lv | Weapon Lv | 全武器共通の単一強化レベル。1 上げると 4 武器全てのステが同時に伸びる |
| ラン中ワークショップ | Run Workshop | ラン内の一時的な乗算バフ強化所 |
