# 03. マシン (Machine) — 永続強化システム

本章では、プレイヤーが操作する中核ユニット **マシン (Machine)** と、その永続強化体系を定める。

## 概要

- マシンは本ゲームにおける「タワー」に相当するユニット。盤面中央に設置され、自動で索敵・攻撃・防御を行う
- マシンは **本体ステータス** と **装着武器** (→ [05-weapons.md](./05-weapons.md)) と **パッチ** から構成される
- 本体ステータスは **ボルト (Bolt)** を消費して恒久的に強化する。ラン (Run) をまたいで保持される
- 本体強化は **16 項目**。すべて Lv 上限なし（パッチスロット数のみ 5 で打ち止め）
- ラン中ワークショップ (→ [04-run-workshop.md](./04-run-workshop.md)) の倍率バフは、本体ステータスに **乗算** で適用される

## ダメージ計算

### 被ダメージ計算式

```
被ダメ = max(0, raw_dmg − 防御力) × (1 − 被ダメ軽減率)
```

- `raw_dmg`: 敵から受ける素のダメージ値
- `防御力`: 本体強化 #4 の値
- `被ダメ軽減率`: 本体強化 #3 の値（0.0〜1.0 未満）

固定値引き算 → 割合軽減 の順で適用。低ダメージ多段ヒットは防御力で完全カット、高ダメージは軽減率で目減りさせる。

### 与ダメージ計算式

```
raw_dmg = マシン基礎攻撃力 × 武器ダメージ倍率
クリ時の与ダメ = raw_dmg × クリ倍率
```

- マシン側は **数値**（基礎攻撃力 #5）
- 武器側は **倍率**（武器 Lv で伸びる）
- クリ判定: 1 撃ごとにクリ率 (#8) でロール、当たれば クリ倍率 (#9) 倍

## 強化項目一覧 (全 16 項目)

5 種別: Defensive 4 / Offensive 5 / Active 2 / Economic 4 / Slot 1

### スケール記法の凡例

| 記法 | 意味 |
|---|---|
| **乗算 (×1.02 / Lv)** | v0.2.0 改訂。理論値は `base × 1.02^Lv` だが、低 Lv で `ceil()` 後の値が長く据え置く（例: Lv 1〜35 で +1 されない）問題を回避するため、**「累積差分 + 最低 +1 保証」** で算出する: `value(Lv) = value(Lv-1) + max(1, ceil(base × factor^Lv) - ceil(base × factor^(Lv-1)))` （`value(0) = ceil(base)`）|
| **線形 (+x / Lv)** | `値 = 初期値 + x × Lv` |
| **漸近 (α = 0.01)** | `r = 0.01 × Lv`, `値 = 1 - 1 / (1 + r)`（0 → 1 に漸近、100% に到達しない） |
| **CD 漸近 (α = 0.01, cap 50%)** | `r = 0.01 × Lv`, `値 = 0.5 × (1 - 1 / (1 + r))`（0 → 0.5 に漸近） |
| **索敵漸近 (base, max, α = 0.01)** | `r = 0.01 × Lv`, `値 = base + (max - base) × (1 - 1 / (1 + r))` |

> **乗算の改訂理由（v0.2.0）**: 旧式の `ceil(base × 1.02^Lv)` は base = 1 の項目（防御力など）で Lv 1〜35 程度まで表示値が 1 から動かない停滞期間が生じていた。改訂式は各 Lv の差分が最低 +1 になることを保証し、整数 base でも 1 Lv ごとに必ず体感成長が乗るようにする。Lv が十分高くなれば `ceil` 差分が支配的になるので、理論値 `base × factor^Lv` と漸近的に一致する。

### 実装メモ: HP リジェネ加算タイミング

HP リジェネは **1 秒ごとに 1 回**「hpRegen 量」 をマシン HP に加算する (毎フレーム加算ではない)。
BigNum は整数のみ扱うため、 毎フレーム `hpRegen × deltaSec` を加算しようとすると
天井丸めで `1 × 0.0167 = 1` に膨らみ、 60FPS で +60HP/秒の暴走リジェネになるため。
`useBattleLoop` は `calcIntervalTicks(累積ms, deltaSec)` で 1000ms 経過ごとに発火する。

## 表示・計算丸めルール

| 種類 | 内部値 | 表示・適用値 |
|---|---|---|
| 効果値（HP / 攻撃力 / リジェネ / etc） | 浮動小数 | **切り上げ整数** |
| ダメージ計算の最終値 | 浮動小数で計算 | **切り上げ整数** |
| コスト計算（cost(Lv) = base × growth^Lv） | 浮動小数 | **切り上げ整数** |
| 倍率・確率（×1.0、50% など） | 浮動小数 | 表示は小数点 1〜2 桁、適用は内部値そのまま |

例:
- Lv 50 最大 HP = `100 × 1.02^50` = 269.158... → 表示 **270**、計算でも 270 として扱う
- 被ダメ = `max(0, 100 - 7.24) × (1 - 0.333)` = 61.86... → 実ダメ **62**

> 「切り上げ」は仕様上の安全側（プレイヤー有利方向）に倒す効果値ではなく、**コストも効果値もダメージも一貫して切り上げ整数**にする方針。実装シンプル、表記ブレなし。

## 永続強化とラン中ワークショップの関係

- マシン本体強化は **ラン間で永続**
- ラン中ワークショップは **ラン中のみ有効な乗算バフ**、本体ステータスに掛け算
- 例:
  - 本体「基礎攻撃力」= 7.24（Lv 100）
  - ラン中 WS「攻撃力倍率」= ×1.5（Lv 5）
  - 実効攻撃力 = 7.24 × 1.5 = 10.86
- 詳細な乗算順序・スタック仕様は [04-run-workshop.md](./04-run-workshop.md) を参照
