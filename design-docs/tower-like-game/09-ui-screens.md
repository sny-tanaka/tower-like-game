# 09. UI 画面構成 / 情報設計

本章では各画面の **情報設計**（情報の種類・配置タイプ・遷移）を定める。
**具体的なデザイン（色・余白・タイポ・アニメーション）は claude design に委譲** し、本章では扱わない。

## 設計思想

- **擬似ルーティング**: URL 遷移は使わず、画面 state で切替（react-router 不使用）
- **画面内タブ**: 1 画面に詰め込まず、機能ごとにタブ分け
- **通貨表示は画面ごとに制限**: その画面で使う通貨のみ表示（不要な情報を出さない）
- **タイトル → 出撃準備 → バトル** の 3 層が基本動線
- ブラウザ戻る・PWA 戻るジェスチャは **考慮不要**（擬似遷移のみ）

## 画面一覧（7 画面）

| # | 画面 | 役割 | 表示通貨 | 構成タイプ |
|---:|---|---|---|---|
| 1 | タイトル | 起動時の入口 | なし | 通常 |
| 2 | 出撃準備 | Tier / 武器 / パッチを選んで「出撃」 | なし | タブ |
| 3 | マシン強化 | マシン本体 16 項目の永続強化 | ボルト | タブ |
| 4 | 武器庫 | 4 武器のステ確認 / 共通強化 | 超合金 | タブ |
| 5 | パッチ庫 | パッチの装着 / 所持 / 合成 | なし | タブ |
| 6 | 設定 | 音 / ゲーム / データ管理 | なし | タブ |
| 7 | バトル | ラン本編（ボトムシート / メニュー / リザルトダイアログを内包） | ネジ + リアルタイム加算中のボルト/超合金 | 通常 |

> ホーム画面 / リザルト画面は廃止。リザルトは **バトル画面内のダイアログ**として表示。

## 画面遷移図

```
   タイトル
      │「続きから / 新規開始」
      ▼
   出撃準備 ◀──── BottomNav ────▶ マシン強化 / 武器庫 / パッチ庫 / 設定
      │
      │「出撃」(LaunchButton)
      ▼
   バトル ─→ リザルトダイアログ ──→ 出撃準備へ
```

- **BottomNav は 5 タブの双方向ナビ**として全画面（バトル / タイトル除く）で `AppShell.footer` に常駐
- **タイトル戻り**は BottomNav には置かず、出撃準備画面のヘッダから（または PWA の閉じる動作）

## 1. タイトル画面

### 主な要素

- ゲームロゴ / タイトル
- 「続きから」ボタン（セーブデータあれば表示）
- 「新規開始」ボタン（初回 or リセット後）
- 「設定」ボタン（音量とデータ管理のサブセット）

### 注意

- ゲームデータ（ボルト / 超合金 / 強化情報）は **表示しない**
- 「続きから」を選ぶとセーブデータをロードして出撃準備画面へ

## 2. 出撃準備画面

### タブ構成

| タブ | 内容 |
|---|---|
| Tier 選択 | 既到達 Tier までから 1 つ選ぶ。ライトな Tier ごとの強敵情報（任意） |
| 初期装備武器 | 4 武器（Laser / Cannon / Thunder / Cutter）から 1 つ選ぶ。**ラン開始時の装備武器**。ラン中は 4 武器すべてを下 HUD から切替可能（CD 3 秒） |
| パッチ確認 | 装着中スロット 1〜N（マシン強化「パッチスロット数」依存）を読み取り専用で表示。変更はパッチ庫で |

### フッタ（タブ共通）

- **2 段固定フッタ**: `LaunchButton`（「出撃」ボタン）+ `BottomNav`（マシン / 武器庫 / パッチ / 設定 への横移動）
- タイトル戻りは BottomNav には含めない

## 3. マシン強化画面

### 構成（タブなし、全 16 項目混在の 2 列リスト）

仕様書初版では 5 カテゴリタブ構成だったが、カテゴリ毎に項目数が偏るためタブ分けは冗長と判断し、**タブを廃止して全項目を 1 画面に混在表示**（カテゴリ順に並べてスクロール）。

| カテゴリ（並び順） | 項目 |
|---|---|
| 防御 (4) | 最大 HP / HP リジェネ/秒 / 被ダメ軽減 / 防御力 |
| 攻撃 (5) | 基礎攻撃力 / 攻撃速度 / 索敵距離 / Critical率 / Critical倍率 |
| アクティブ (2) | アクティブ威力 / アクティブ CD 減少 |
| 経済 (4) | ネジ獲得倍率 / ボルト獲得倍率 / 超合金獲得倍率 / パッチドロップ率倍率 |
| スロット (1) | パッチスロット数 |

### 各項目（`UpgradeCard`）の表示要素

- 現 Lv / 現効果値 / 次 Lv コスト（ボルト、**通貨アイコンは付けない**：カード単位で固定）
- 強化ボタン: **+1 / +5 / Max** の 3 ボタン
- ボルト不足時は disable

### ヘッダ

- ボルト残高（このタブの主要通貨）

### フッタ

- `BottomNav`（`AppShell.footer` に集約）

## 4. 武器庫画面

### タブ構成

| タブ | 内容 |
|---|---|
| 武器詳細 | **4 武器を縦並びで全部表示**（武器ごとの情報量が少ないためタブ内タブを廃止、スクロールで OK）。各武器の通常攻撃 / アクティブ / 固有ステの現値と説明文 |
| 共通強化 | 武器強化 Lv の表示と強化ボタン（+1 / +5 / Max）。1 Lv 上げると 4 武器すべての値が同時に伸びる |

### ヘッダ

- 超合金残高（このタブの主要通貨）

### フッタ

- `BottomNav`

## 5. パッチ庫画面

### タブ構成

| タブ | 内容 |
|---|---|
| 装着 | スロット 1〜6 への装着・取り外し。**空きスロットタップで「装着候補ダイアログ」（在庫から選ぶピッカー）を開き、 選んで `equipPatch`**。装着済みスロットタップは従来通り `unequipPatch`。同名パッチの重複装着は不可。詳細フローは [06-patches.md](./06-patches.md) 参照 |
| 所持 | インベントリ一覧（同名同 Tier ごとに集約表示、count 付き） |
| 合成 | 「上限 Tier」+/- ステッパー + 「実行」ボタン。所持 Tier の最大が初期値（実質「全合成」） |

### ヘッダ

- 通貨表示なし（パッチは通貨を使わない）

### フッタ

- `BottomNav`

## 6. 設定画面

### タブ構成

| タブ | 内容 |
|---|---|
| 音 | BGM 音量（0〜100）/ SE 音量（0〜100） |
| ゲーム | バイブレーション ON/OFF（v0.2.0 でゲームスピード切替廃止に伴い「初期速度倍率」設定も削除） |
| データ | エクスポート（JSON ダウンロード）/ インポート（JSON ファイル選択）/ リセット（2 段階確認） |

### フッタ

### 多言語

## 7. バトル画面

### レイアウト

| エリア | 内容 |
|---|---|
| 上 HUD | マシン HP バー / 現 Tier / 現ウェーブ |
| 中央 | マシン + 敵 + 攻撃エフェクト + **索敵円（常時 ON、切替なし）** |
| 下 HUD | **通貨エリア (ネジ残高 `size=lg` + ラン中獲得ボルト累計 `size=md` を並列表示。 獲得ボルトは `bolt - runStartBolt` を 0 クランプ、リザルト `earnedBolt` と一致)** / **武器切替アイコン × 4**（Laser / Cannon / Thunder / Cutter、現装備ハイライト、切替 CD 3 秒）/ アクティブボタン（CD バー込み、「発動 = 0 → 時計回りで満タンに溜まる」、ラン開始時は CD 満タン状態スタート）+ **直下に「アクティブ手動/自動」トグル** / 一時停止ボタン（**v0.2.0 で「pause + メニュー開」 が完全同期。メニュー専用ボタンは廃止**） / **スクリーンセーバーボタン**（アイコンは `ice`）。v0.2.0 で速度切替ボタンは廃止 |

> BottomNav は配置しない（バトル中は他画面に遷移しない）。

### ボトムシート（タップで開閉）

- ラン中ワークショップ 4 項目（攻撃力倍率 / 攻撃速度倍率 / HP 倍率 / ネジ獲得倍率）
- 各項目: 現 Lv / 現倍率 / 次 Lv コスト / +1 / +5 / Max ボタン
- 戦闘中も一時停止中も開閉可能

### メニュー（オーバーレイ）

- **撤退** ボタン（確認ダイアログあり）
- 設定（音量のみ）
- **一時停止ボタンと完全同期**: メニューを開く = pause 状態に入る、メニューを閉じる = pause 解除（v0.2.0 で統合。メニュー専用ボタンは UI から削除）
- **バックグラウンド自動 pause**: 戦闘画面マウント中に `document.visibilitychange` を listen し、`document.hidden` かつラン中であれば `setPaused(true)` を呼ぶ。復帰時は自動再開せず、ユーザーがメニューを閉じて手動再開する

> アクティブ手動 / 自動 切替トグルは、頻繁な操作が想定されるため、メニューから取り出して **下 HUD のアクティブボタン直下に常駐** させる。

### ダメージ表示

- **毎ヒットごとにポップ**（過密時はスポーンキャップで体数制御）

### スクリーンセーバーボタン

- バトル画面のどこかに常時表示
- タップで **スクリーンセーバー** ダイアログ起動
- スクリーンセーバー中もゲームは進行
- 画面のどこかをタップで復帰

#### スクリーンセーバーの内容

- ゲームのトンマナに合った軽量アニメーション（ロゴが画面内をゆっくり移動、または抽象的な背景アニメなど）
- claude design に委譲

### リザルトダイアログ

- バトル終了時（クリア / 全滅 / 撤退）にバトル画面に重なるダイアログとして表示
- 表示要素:
  - ヘッダー: 「クリア」「全滅」「撤退」のステータス
  - 統計: 到達 Tier / 到達 Wave / 撃破数 / 所要時間
  - 獲得: ボルト / 超合金 / ドロップパッチ一覧
  - アクション: **「出撃準備へ」ボタン 1 つ**（タイトル戻りは出撃準備画面のヘッダ経由）

## ダイアログ系（独立画面ではない、重ねて表示）

| ダイアログ | 発生タイミング |
|---|---|
| 撤退確認 | バトル画面メニューから「撤退」 |
| **リザルト** | バトル終了時（クリア / 全滅 / 撤退） |
| データリセット確認 | 設定 / データタブ「リセット」（2 段階） |
| インポート確認 / エラー | 設定 / データタブ「インポート」 |
| **スクリーンセーバー** | バトル画面のスクリーンセーバーボタン |
| トースト（保存成功 / 失敗）| ライフサイクルイベント時 |

## セーブ / ロードの UX

- **完全オートセーブ**: ユーザーが意識する保存ボタンは置かない
- IndexedDB への書き込みは内部で適切にリトライ（指数バックオフ）
- 失敗が継続した場合のみエラーログ（v1 ではユーザー通知なし）
- 容量超過時のフォールバックは TBD

## 横断的な UI ルール

- **縦画面固定**（スマホ片手操作前提）
- **デザインガイド** は別途 claude design が作成（色・タイポ・アイコン・余白）
- アクセシビリティ要件は claude design に委譲
