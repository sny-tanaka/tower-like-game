# 09 — UI 画面 (UI Screens)

本作の画面構成、各画面の役割、画面間の遷移を整理する。
URL ルーティングは増やさず、**単一 SPA 内の `screen` ステートによる擬似ルーティング** を前提とする
（PWA を 1 つの URL で完結させ、戻る挙動も自前で持つ）。

---

## 1. 画面一覧

| ID | 画面名 | 役割 |
|---|---|---|
| `home` | ホーム | ハブ画面。各メニューへの導線。最新ラン要約・現在の Tier 目標を表示 |
| `machine` | マシン強化 | マシン本体 16 項目をボルトで強化 |
| `armory` | 武器庫 | 全武器共通の武器強化 Lv を超合金で強化 |
| `patches` | パッチ庫 | 所持パッチの閲覧・装着・合成 |
| `settings` | 設定 | 各種設定、データ管理（バックアップ/リセット） |
| `prepare` | プレイ準備 | 挑戦 Tier / 武器 / 装着パッチを確認して出撃 |
| `battle` | 戦闘 | 実戦闘画面（詳細は `01-battle-screen.md`） |
| `result` | リザルト | ラン終了時の成果サマリー |

> TBD: ホームの「最新ラン要約」エリアに何を出すか（最高到達 Tier / 直近獲得通貨 / 装着パッチ等）。

## 2. 各画面の主な要素

### 2.1 `home` — ホーム

- ロゴ / バージョン表記
- 「プレイ」ボタン（最上位の動線、最も大きい）
- メニュー: マシン強化 / 武器庫 / パッチ庫 / 設定
- 最新ラン要約カード（任意）

### 2.2 `machine` — マシン強化

- ヘッダー: 現在のボルト残高
- 16 項目をカテゴリでセクション分け
  - Defensive / Offensive / Active / Economic / Slot
- 各項目カード:
  - 項目名 / 現 Lv / 現効果値 / 次 Lv 効果値 / 必要ボルト / 強化ボタン
- 一括強化（max まで購入）動線

> TBD: 一括強化の要否、項目検索/フィルタ UI の必要性。

### 2.3 `armory` — 武器庫

- ヘッダー: 現在の超合金残高
- 4 武器をタブまたは横スクロールカードで切替: Laser / Cannon / Thunder / Cutter
- ヘッダー直下に **共通武器強化 Lv**（全武器共通の 1 個）の強化セクション
  - 現 Lv / 全武器の現倍率プレビュー / 次 Lv での値プレビュー / 必要超合金 / 強化ボタン
- 各武器のカードには参照表示のみ:
  - 現 Lv での 基礎ダメ倍率 / 攻撃速度 / アクティブ威力 / 固有ステ
  - 通常攻撃挙動とアクティブの説明文（動画/GIF は任意）

> TBD: 武器ごとの説明テキスト、アイコン、視覚差別化。

### 2.4 `patches` — パッチ庫

- 所持パッチ一覧（カテゴリフィルタ: Offensive / Defensive / Economic / Utility）
- 装着スロット表示（マシン強化の Slot に応じて 1〜6）
- 操作:
  - パッチを装着 / 解除
  - 同名 Tier 2 個を **合成** → 1 個 Tier UP
  - 同名パッチは装着 1 個まで（重複装着不可）
- 強化通貨はなし（合成のみ）

> TBD: 合成 UI（2 個選択 → 確認）、パッチ詳細モーダル、ソート順。

### 2.5 `settings` — 設定

- **アクティブスキル発動**: 手動 / 自動 ラジオ
- **サウンド**: BGM 音量 / SE 音量 / ミュート
- **速度倍率の初期値**: x1 / x2 / x3 / x5
- **データ管理**:
  - エクスポート（JSON 形式でセーブをダウンロード）
  - インポート（JSON を読み込んでセーブ上書き）
  - 全データリセット（確認モーダル 2 段）
- **バージョン情報 / クレジット**

> TBD: その他オプション（索敵円表示 ON/OFF、ダメージ数値表示の粒度、UI 言語切替）。

### 2.6 `prepare` — プレイ準備

- 挑戦 Tier セレクタ（直近到達 Tier + α まで）
- 使用武器セレクタ（4 種）
- 装着パッチの最終確認（スロット内訳）
- マシンステータスのプレビュー
- 出撃ボタン

> TBD: 「直近到達 +n」の n の値、プレビュー値の表示密度。

### 2.7 `battle` — 戦闘

- 詳細は `01-battle-screen.md` を参照。
- ステート上は `battle` 1 枚だが、内部にラン中ワークショップ（ボトムシート）や撤退確認モーダルを持つ。

### 2.8 `result` — リザルト

- 到達 Tier / 到達ウェーブ
- 獲得通貨: ネジ（消滅マーク付） / ボルト / 超合金
- 加算後の永続残高: ボルト / 超合金
- ドロップしたパッチ一覧
- 戻る動線: ホームへ / もう一度プレイ準備へ

> TBD: リザルトの演出時間、シェア機能の有無、ベスト更新時の特別表示。

## 3. 画面遷移図

```
                ┌──────────┐
                │  home    │◀───────────────────┐
                └────┬─────┘                    │
        ┌───────────┼───────────┬───────────┐  │
        ▼           ▼           ▼           ▼  │
   ┌─────────┐ ┌────────┐ ┌─────────┐ ┌──────────┐
   │ machine │ │ armory │ │ patches │ │ settings │
   └────┬────┘ └───┬────┘ └────┬────┘ └────┬─────┘
        │          │            │            │
        └──────────┴──┬─────────┴────────────┘
                     │ (戻る = home)
                     │
            ┌────────▼─────────┐
            │     prepare      │
            └────────┬─────────┘
                     │ 出撃
                     ▼
            ┌──────────────────┐
            │      battle      │ (撤退/GameOver)
            └────────┬─────────┘
                     ▼
            ┌──────────────────┐
            │      result      │──→ home / prepare
            └──────────────────┘
```

- **戻る**: 戦闘中はシステムの「戻る」を **無効化または撤退確認** に差し替える（誤操作で進行が消えるのを防ぐ）。
- URL ルーティングは追加せず、`screen` ステートのみで遷移管理する。

> TBD: ブラウザ戻るボタンと PWA の戻るキーの扱い、戦闘以外の各画面での戻る挙動。

## 4. 設定画面の詳細仕様

### 4.1 アクティブ手動/自動切替

- 手動: 戦闘画面のアクティブボタンタップで発動。
- 自動: CD 明け次フレームで自動発動。手動タップ無効化。
- ラン中の切替: 不可。次のラン開始から反映（ラン中に変更しても挙動は変わらない）。

> TBD: ラン中切替を許すか、武器ごとに個別設定できるか。

### 4.2 サウンド

- BGM / SE 別スライダ + ミュート。
- 値は IndexedDB に保存。

### 4.3 データ管理

#### エクスポート

- IndexedDB の全データを 1 つの JSON にまとめてダウンロード。
- ファイル名は `tower-like-game-save-YYYYMMDD-HHmm.json` を想定。

#### インポート

- JSON を読み込んで全データを上書き。
- スキーマバージョンが現行と異なる場合は警告。
- インポート前に「現在のデータが上書きされる」旨を 1 段モーダルで確認。

#### 全データリセット

- 永続データを完全削除。
- 確認モーダル **2 段**（誤操作防止）。
- 初回プレイ状態に戻る。

> TBD: スキーマバージョン番号の付け方、後方互換の維持方針、クラウドバックアップの有無（現状はなしの方針）。

## 5. セーブ・ロードの UX

- 保存先: **IndexedDB**。
- 保存タイミング:
  - メタ進行画面での強化 / 装着 / 合成: 操作直後
  - 戦闘終了（リザルト到達）時: 通貨永続化と同時に保存
  - 設定変更: 即時保存
- 戦闘中のオートセーブは持たない（途中復帰機能を持たない）。
- 起動時に IndexedDB からロード。データが無ければ初期状態で開始。

### 失敗時の挙動

- 保存失敗時はトーストで明示。次回操作時に再試行。
- ロード失敗（スキーマ破損等）の場合は「インポートを試す / 初期化する」の選択モーダル。

> TBD: トースト UI の位置・表示時間、保存失敗時のリトライ戦略、容量超過時のフォールバック。

## 6. 横断的な UI ルール

- 全画面で **下部に親指帯（主要アクション領域）** を確保する。
- 戻る動線は必ず画面左上 or システムジェスチャに対応。
- モーダル / ボトムシートは画面内最大 1 つ（重ね表示しない）。
- カラー / タイポ / アイコンの統一ルールは別途デザインガイドで定義する。

> TBD: デザインガイド本体、SCSS 命名規約、アクセシビリティ要件（コントラスト・読み上げ）。
