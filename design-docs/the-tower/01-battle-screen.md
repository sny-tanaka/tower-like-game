# 01. バトル画面仕様

出典: 公式 wiki ページ #59（バトル画面）。一部補足として #42（初心者指南）。

バトル画面は本ゲームの主戦場。塔・敵・各種 HUD・操作系のレイアウトと振る舞いを以下に整理する。

## 画面レイアウト全体（wiki #59）

### 画面上部 — 通貨欄
- 常時表示: コイン、ジェム、ストーン。
- `∨` マークをタップ: その他通貨を一覧表示。

### 画面中段
- 中央: タワー本体（攻撃範囲を示す薄い円形ラインを伴う）。
- 中央外周: 「防壁」を取得している場合はレンガ状の円が周囲に表示される。
- 左の四角枠（自陣ステータス）: 剣 = 塔のダメージ、ハート = ヘルス回復速度、C = コイン倍率。ゲージはタワー本体のヘルス（0 で敗北）。タップで**コイン倍率の内訳**を表示。
- 右の四角枠（敵陣ステータス）: 現在のティアとウェーブ、剣 = 敵基礎攻撃力、ハート = 敵基礎ヘルス。タップで**ウェーブ情報ダイアログ**を表示（後述）。

### 画面下部 — アップグレード欄
- 敵を倒して得た**キャッシュ**を使い、その場でタワーを一時的に強化していくアクション群。
- 並ぶカテゴリは攻撃・防御・ユーティリティ。

### 画面下部のタブアイコン（wiki #59）
バトル中も操作可否がアイコンごとに異なる。

| アイコン | バトル中の操作可否 | 備考 |
|---|---|---|
| ストア | 可 | デイリーチェック用 |
| 最小化ボタン | 可 | UI を畳む |
| デイリーミッション | 可 | 赤マーク時は要確認。ただしワークショップ/スキン変更系ミッションは別画面操作が必要 |
| 設定 | 可 | 言語、ダメージ表示 ON/OFF など |
| カード | 一部可 | ロック付きカードはバトル中不可。それ以外は差替可（ボス接近中は不可） |
| 研究所 | 一部可 | 項目変更・加速は可。「範囲」「ショックウェーブサイズ」の調整スライダーはバトル中不可 |
| ターゲット指定 | 可 | 「ターゲットの優先順位」研究で追加されるアイコン |
| モジュール | 一部可 | スロット装填中身の変更は不可。ガチャと未使用モジュールのマージは常時可 |
| イベント | 一部可 | ボット強化のみバトル中不可 |
| オーブの位置調整 | 一部可 | エクストラオーブアジャスター研究 + インナーオーブカード装着時に表示。ボスが画面上にいる時は変更不可 |
| ギルド | 一部可 | ガーディアン周りはバトル中変更不可 |
| ラウンド終了 | 可 | 現在のバトルを強制終了する |

## タワー周辺の表示物（wiki #59）

| 要素 | 内容 |
|---|---|
| タワー周囲の薄い線 | 攻撃範囲。敵がこのラインを超えて中に入るとタワーは自動で迎撃 |
| レンガ状の円 | ワークショップの防御「防壁」 |
| 中段左にあるレンガ横ゲージ | 防壁のヘルス |
| 上部の紫のゲージ | パークの進行状況。MAX になったらタップしてパークを選択 |
| その下に出るゲージ | ボスのヘルスメーター。倒した後もしばらく残り、タップで**与えたダメージの内訳**を表示 |
| 漂うジェム | タップで 2 ジェム獲得。1 ラウンドで最大 10 回まで出現。左側に表示される広告ジェムは広告視聴で 5 ジェム |

### 戦闘中ログ表示（wiki #59）
- **茶色の文字**: ワークショップユーティリティ「敵のレベルスキップ」発動時、またはウェーブスキップカードで「ウェーブスキップ」発動時に表示。
- **緑色の文字**: ユーティリティ「無料アップグレード」発動時に表示。

## スピード調整・一時停止（wiki #59）

- `－ x5.0 ＋` ボタン: ゲームの早送り倍率を変更。
- ゲームスピードの研究で**最大 5 倍**、特典込みで**最大 6.3 倍**。
- 表示値 5 倍は実際には 4 倍速程度。
- **`－` を連打して 0 倍速にすると一時停止する**（明示的な PAUSE ボタンではなく、減速の延長線で停止扱い）。

## ウェーブ情報ダイアログ（wiki #59）

中段右の敵陣ステータスをタップすると現在のウェーブ情報が表示される。記載項目は以下。

| 項目 | 内容 |
|---|---|
| 四角形の敵 | ノーマルタイプの一覧と出現率（合計 100%）。ボス出現ウェーブはボス 100% |
| 三角形の敵 | エリート敵。出現率は 3 種でシェアし表示上は 1/3 値。1 体確定で 33% 表示、2 体確定で 100% 表示 |
| 五角形の敵 | 艦隊。ティア 14 以降のみ。出現時のみ 33.33% 表示 |
| ヘルス | 敵耐久値（基礎値 × 倍率） |
| 攻撃 | 敵攻撃力 |
| 速度 | 敵がタワーへ向かう速度 |
| 集団 (Mass) | 質量。ノックバック 1 回の押し戻し距離に関係 |
| ウェーブタイマー | **1 ウェーブの敵出現時間 = 26 秒固定** |
| ウェーブクールダウン | ウェーブ間の小休止。敵は出現しない。**ウェーブアクセラレータ**で短縮可能 |
| プロテクターの保護範囲 | プロテクターのバリア範囲。ウェーブ進行で拡大。研究で軽減可 |
| Protector dmg reduction | バリア内の敵が受けるダメージ減衰率。**基本 60% 固定**。研究で軽減可 |
| アクティブな敵 | 画面上に残っている敵数 |
| 出現率 | 1/8 秒ごとの抽選確率。最大 56%（どのティアでも 6500 ウェーブで上限） |
| 敵の攻撃/ヘルスレベルスキップ | 毎ウェーブ行われる敵強化を無効化した累計回数 |

## 敵スポーン仕様（wiki #59）

### 通常敵（四角形）
- 1 ウェーブは 26 秒。1/8 秒ごとに「出現率」の確率で 1 体出るか抽選。1 ウェーブの抽選回数は **208 回**（8 × 26）。
- 平均敵数 ≒ 208 × 出現率。
- 出現が決まったら出現割合に従って各タイプ（ベーシック・高速・戦車・遠隔部隊・プロテクター）に振り分け。
- **敵のバランスカード**装填時: 抽選成功ごとに追加でもう 1 体出すかどうかを 80% で再抽選 → 単純に **1.8 倍**の敵数になる。

### エリート（三角形）
- ティア 1 では 500 ウェーブごとに出現確率が 1 段階上昇: 500 で 1%、1000 で 4%、1500 で 9%、… nの2乗% で増加。
- ティア n では「500 × 0.9^(n-1)」ウェーブごとに 1 段階。
- 表示は 3 タイプでシェアするため 1/3 値。
- ティア 1 で **17,000 ウェーブで毎ターン 2 体確定**（最終段階）。
- ティア 16 では 3,294 ウェーブで上限到達済。

### 艦隊（五角形、wiki #59 表より）

| ティア | 最初のウェーブ | その後の頻度 |
|---|---|---|
| Tier14 | 2495 | 1000 |
| Tier14 + レジェンドリーグ | 895 | 30 |
| Tier15 | 1495 | 750 |
| Tier16 | 995 | 500 |
| Tier17 | 495 | 250 |
| Tier18 | 95 | 100 |
| Tier19 | 45 | 50 |
| Tier20 | 5 | 10 |
| Tier21 | 5 | 10 (2 体同時) |

ウェーブスキップカードで該当ウェーブを飛ばしても、艦隊の出現ウェーブがズレるだけで艦隊は必ず出現する。

### スポーンキャップ（wiki #59）
画面上に存在できる上限。

| カテゴリ | 上限 |
|---|---|
| 通常敵 | 120 体 |
| ボス | 10 体 |
| エリート | 20 体 |

艦隊と随伴敵は通常敵にカウントされる模様。

### 全敵共通仕様（wiki #59）
- 敵がタワーを 1 回攻撃するごとに、その個体のダメージが **+4%** 上昇。
- 敵が **3 ウェーブ以上**生存すると、撃破時のコインが **半減**。
- 敵が **1 ウェーブ以上**生存すると、1 ウェーブごとにその敵の質量が **+4%** 増加。

## 敵タイプ仕様（wiki #59, #42）

### 通常敵

| 名前 | コイン | ヘルス倍率 | 速度 | 特徴 |
|---|---|---|---|---|
| ベーシック (Basic) | 0 | 1x | 1x | 基礎値同等。クリティカルコイン装着時のみ確率で 1 コイン取得可（通常弾以外の撃破は 100% クリティカル扱い） |
| 高速 (Fast) | 2 | 1x | 2x | ベーシックの 2 倍速。ノックバック耐性は通常 |
| 戦車 (Tank) | 4 | 5x | 0.5x | ベーシックの半分速度、5 倍ヘルス |
| 遠隔部隊 (Ranged) | 2 | 1x | 1x | タワー射程内の一定距離まで接近して弾を撃つ |
| プロテクター (Protector) | 3 | 0.6x | - | オーブとデスレイを無効化するバリアを展開。バリア内の敵は**ダメージ 60% 軽減**。ヘルスは基本の 60% |
| ボス | 5 | 20x | - | **10 ウェーブごと**に出現。ノックバック無効で必ず衝突 |

### エリート（三角形 / wiki #42）
すべてのエリートはオーブ、デスレイ、ショックウェーブ、ブラックホールの影響を受けない。倒すと**エリートセル**を落とす。

| 名前 | コイン | ヘルス | 特徴 |
|---|---|---|---|
| 吸血鬼 | 4 | 2x | ノックバック耐性あり。割合ダメージの吸血。吸血中はヘルス回復無効 |
| レイ | 4 | 1x | ノックバック無効。射程内で停止し**30 秒チャージ**して 2 倍ダメージの光線を放つ |
| スキャッター | 4 | 2x | ノックバック耐性あり。倒すとヘルス半減の 2 個体に分裂、これを **4 回**繰り返す |

### 艦隊（五角形）
ティア 14 以降のみ出現。**トゲダメージ 1/10** など更に高い耐性を持つ。それぞれ個別の厄介な能力を持つ。

### 究極ヒート（wiki #59）
トーナメントなどで「ベーシックの究極」「究極の高速」「究極のタンク」「究極の遠隔」「究極のプロテクター」というヒートが設定されることがある。
- 「ベーシックの究極」: ベーシックが一定確率で他の敵に入れ替わる効果（入れ替わった敵が究極の効果を受けていればそれも適用）。
- 「究極の高速」: 他の敵を数体高速と同じ速度にする。
- 「究極のタンク」: 戦車にボス耐性を付与しオーブのボスヒット効果対象に。一定距離で停止し攻撃しない。300 秒周期で究極/非究極を切替。**1000 ウェーブで常時究極化**。

## プレイヤー操作まとめ（wiki #59, #42）

| 操作 | 効果 |
|---|---|
| 画面下部のアップグレードをタップ | キャッシュ消費でタワーを一時強化 |
| 漂うジェムをタップ | 2 ジェム獲得（左の広告ジェムは 5 ジェム） |
| 中段右の敵陣枠タップ | ウェーブ情報ダイアログ表示 |
| 中段左の自陣枠タップ | コイン倍率の内訳表示 |
| ボスヘルスゲージタップ | 与えたダメージの内訳表示 |
| 紫ゲージ MAX 時タップ | パーク選択 |
| 速度 `－` 連打で 0 倍 | 一時停止 |
| 速度 `＋` | 早送り（研究で最大 5x、特典込みで最大 6.3x） |
| ラウンド終了ボタン | 強制終了 |
| ターゲット指定アイコン | ターゲット優先順位設定（研究で解放） |
| オーブ位置調整アイコン | オーブ初期位置調整（研究 + カードで解放、ボス時不可） |
| 設定 | 言語、ダメージ表示 ON/OFF など |

## 一時停止・リスタート・リプレイの扱い

- **一時停止**: 専用ボタンは無く、`－` 連打でゲームスピードを 0 にすることで実現（wiki #59）。
- **リスタート / ラウンド終了**: 「ラウンド終了」ボタンで現在のバトルを終了して非戦闘画面に戻る。マイルストーンランで 4500 ウェーブを超えたら任意で終了可（wiki #59）。
- **リプレイ機能**は wiki に明記なし。
